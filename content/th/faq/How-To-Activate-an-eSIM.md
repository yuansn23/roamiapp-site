> **บันทึกจากบรรณาธิการ:** การเปิดใช้งาน eSIM ใช้เวลาประมาณห้านาที — คุณสแกน QR code หรือกรอกที่อยู่ SM-DP+ แล้วรอโปรไฟล์ดาวน์โหลด ขั้นตอนด้านล่างนี้คือขั้นตอนเดียวกับที่ทีมสนับสนุนของเราใช้ ทดสอบแล้วบน iOS 17/18 และ Android 13/14/15 ทำตามเส้นทางสำหรับโทรศัพท์ของคุณแล้วคุณจะออนไลน์ได้ก่อนขึ้นเครื่อง

**สรุปสั้น ๆ ก่อนเริ่ม:** การเปิดใช้งาน eSIM หมายถึงการดาวน์โหลดโปรไฟล์ของผู้ให้บริการแบบดิจิทัลลงบนโทรศัพท์ของคุณ ไม่ว่าคุณใช้แบรนด์ไหน สูตรก็เหมือนกัน: โทรศัพท์ที่ปลดล็อกแล้ว การเชื่อมต่อ Wi-Fi ที่เสถียร และ QR code (หรือข้อมูลสำหรับกรอกเอง) จากผู้ให้บริการ เปิดการตั้งค่าเซลลูลาร์ แตะ "เพิ่ม eSIM" สแกนหรือพิมพ์ แล้วรอประมาณสองนาที

ถ้าเป็นครั้งแรกของคุณ [eSIM คืออะไร?](/faq/what-is-esim/) จะอธิบายเทคโนโลยีนี้ และ [การเปิดใช้งาน eSIM คืออะไร?](/faq/what-is-esim-activation-and-how-does-it-work/) จะอธิบายว่าเกิดอะไรขึ้นเบื้องหลังเมื่อคุณสแกน

> **ใช้ iPhone อยู่?** หน้านี้ครอบคลุมทั้งสองแพลตฟอร์ม แต่คู่มือ iOS ละเอียดกว่า สำหรับความต่างระหว่างเวอร์ชัน iOS, Quick Transfer และการลงทะเบียน iMessage/FaceTime ใหม่ อ่าน [วิธีเปิดใช้งาน eSIM บน iPhone](/faq/how-to-activate-esim-on-iphone/) ใช้ iPhone 16 และเห็น "Unable to Activate"? ดู [คู่มือ eSIM iPhone 16](/faq/2026-ultimate-guide-iphone-16-esim-activation-solutions/)

## โทรศัพท์ของคุณรองรับ eSIM หรือไม่?

ตรวจใน 10 วินาที: โทร `*#06#` แล้วมองหาตัวเลข 32 หลักที่เรียกว่า **EID** ถ้ามีแสดงว่าคุณพร้อมแล้ว สำหรับรายการทั้งหมดแยกตามรุ่น — ทุกแบรนด์ Android และ iPhone รุ่นเก่า — ดู[รายการความเข้ากันได้ของ eSIM ฉบับเต็ม](/compatibility/)

## เช็กลิสต์ก่อนเปิดใช้งาน eSIM

ความล้มเหลวในการเปิดใช้งานส่วนใหญ่ป้องกันได้ก่อนที่คุณจะสแกนอะไรเลย ทำการตรวจสอบทั้งหกข้อนี้ก่อน

| รายการตรวจ | ผ่านเมื่อ |
|---|---|
| โทรศัพท์ปลดล็อกแล้ว | iPhone: Settings > General > About > Carrier Lock ขึ้น "No SIM restrictions" |
| Wi-Fi เสถียร | เชื่อมต่อ Wi-Fi บ้านหรือที่ทำงาน ไม่ใช่สนามบินหรือโรงแรม |
| รู้รหัสผ่าน | คุณพิมพ์รหัสผ่านหน้าล็อกได้เมื่อถูกถาม |
| QR พร้อมใช้ | อีเมลเปิดอยู่บนโน้ตบุ๊ก แท็บเล็ต หรือกระดาษที่พิมพ์แล้ว |
| หน้าจอสว่าง | เครื่องที่แสดง QR ตั้งความสว่าง 100% |
| มี EID | `*#06#` แสดง EID |

ข้ามข้อใดข้อหนึ่งไป คุณก็มักจะต้องเข้าคิวแก้ปัญหา สาเหตุความล้มเหลวสามอันดับแรกที่พบบ่อยที่สุด เรียงตามลำดับ: โทรศัพท์ล็อกเครือข่าย, Wi-Fi อ่อนกลางคันระหว่างดาวน์โหลด และการสแกนด้วยแอป Camera แทนที่จะทำผ่าน Settings

### สิ่งที่ควรเตรียมก่อนสแกน

ตารางด้านบนเป็นเรื่อง *การตรวจสอบ* รายการนี้เป็นเรื่อง *การลงมือทำ* — สิ่งที่ควรทำก่อนแตะ "เพิ่ม eSIM" เพื่อไม่ให้ต้องตื่นตูมกลางคันระหว่างตั้งค่า

1. **บันทึก QR code ไว้ในรูปภาพ** แคปหน้าจอหรือดาวน์โหลดรูป เพื่อใช้ "เลือกรูปภาพ" แทนการเล็งกล้องไปที่จออีกเครื่อง ถ้า code อยู่ในอีเมล วิธีนี้ยังทำให้คุณไม่ต้องเปิดกล่องจดหมายใหม่ตอนนั้นด้วย
2. **แคปหน้าจอที่อยู่ SM-DP+ และรหัสเปิดใช้งาน** ข้อความสองชุดนี้คือทางสำรองแบบออฟไลน์ของคุณ เมื่อบันทึกไว้แล้ว QR code เสียก็ไม่ทำให้คุณติดขัด
3. **ดาวน์โหลดแอปของผู้ให้บริการและล็อกอิน** Roami, Airalo และ Holafly รองรับติดตั้งแตะเดียวจากในแอป — แต่ต้องล็อกอินไว้แล้วก่อนออกจาก Wi-Fi ที่ใช้ดี
4. **ชาร์จโทรศัพท์เกิน 50%** การดาวน์โหลดโปรไฟล์เล็กมาก แต่ถ้าเครื่องดับกลางคันระหว่างติดตั้ง อาจเหลือโปรไฟล์ครึ่ง ๆ กลาง ๆ ที่คุณต้องลบแล้วเพิ่มใหม่
5. **จำรหัสผ่านหน้าล็อกของคุณให้ได้** ทั้ง iOS และ Android จะถามรหัสเพื่ออนุมัติการติดตั้ง ถ้าคุณใช้แต่ Face ID หรือลายนิ้วมือมาตลอด ให้พิมพ์รหัสผ่านสักครั้งก่อนเพื่อให้แน่ใจว่าจำได้
6. **ยืนยันว่าโทรศัพท์ปลดล็อกแล้ว** บน iPhone: Settings > General > About > Carrier Lock บน Android: สอบถามผู้ให้บริการ หรือทดสอบด้วยซิมของเพื่อนจากเครือข่ายอื่น
7. **ติดตั้งบน Wi-Fi ที่บ้าน ไม่ใช่ Wi-Fi สนามบิน** คุณติดตั้งได้ล่วงหน้าหลายสัปดาห์ก่อนเดินทาง แพ็กเกจจะยังไม่ทำงานจนกว่าโทรศัพท์ของคุณจะเชื่อมต่อเครือข่ายที่ปลายทาง
8. **ตัดสินใจว่าสายไหนทำหน้าที่อะไร** ถ้าคุณจะเก็บซิมบ้านไว้ วางแผนตอนนี้เลย: eSIM ท่องเที่ยวดูแลข้อมูล ซิมบ้านดูแลสายและข้อความ เรามีเนื้อหาส่วนนี้ด้านล่าง

## วิธีเปิดใช้งาน eSIM บน iPhone

iPhone ทุกรุ่นตั้งแต่ XS เป็นต้นไปใช้เส้นทางเดียวกัน ไปที่ **Settings > Cellular** แตะ **Add eSIM** (หรือ **Add Data Plan**) เลือก **Use QR Code** แล้วถือโทรศัพท์ให้นิ่งห่างจาก code ประมาณ 15 ซม. เมื่อขึ้น "Cellular Setup Complete" ก็เสร็จแล้ว — การดาวน์โหลดมักใช้เวลา 30–60 วินาที

ไม่มีกล้องใช้? แตะ **Enter Details Manually** แล้ววางที่อยู่ SM-DP+ และรหัสเปิดใช้งานจากอีเมลของผู้ให้บริการ

สำหรับขั้นตอนใหม่ของ iOS 18, Quick Transfer ระหว่าง iPhone และการลงทะเบียน iMessage/FaceTime ใหม่หลังสลับสาย ดู [วิธีเปิดใช้งาน eSIM บน iPhone](/faq/how-to-activate-esim-on-iphone/)

## วิธีเปิดใช้งาน eSIM บน Android

ชื่อเมนูต่างกันไปตามแบรนด์ แต่เส้นทาง eSIM ของ Android ทุกเครื่องคือ "เปิดการตั้งค่า หาเมนูเพิ่ม eSIM สแกนหรือพิมพ์"

| แบรนด์ | เส้นทางไป "Add eSIM" |
|---|---|
| Samsung Galaxy (One UI 5–7) | Settings > Connections > SIM Manager > Add eSIM |
| Google Pixel (Android 13–15) | Settings > Network & internet > + ข้าง SIMs > Download a SIM instead? |
| OnePlus (OxygenOS 13–14) | Settings > Wi-Fi & Network > SIM & Network > Add eSIM |
| Xiaomi (MIUI/HyperOS) | Settings > SIM Cards & Mobile Networks > Add eSIM |
| Motorola | Settings > Network & Internet > Mobile Network > Add Carrier |
| แบรนด์อื่น | ค้นหา "eSIM" ใน Settings |

ถ้าไม่พบตัวเลือกนี้ รุ่นของคุณมักไม่มีฮาร์ดแวร์ eSIM — ยืนยันได้จาก[รายการความเข้ากันได้ของอุปกรณ์](/compatibility/)

### การกรอกเองบน Android

เมื่อ QR สแกนไม่ได้ ให้มองหา "Enter activation code manually" หรือ "Need help?" ในหน้า Add eSIM แล้วพิมพ์ที่อยู่ SM-DP+ และรหัสเปิดใช้งาน วิธีนี้ใช้ได้กับโทรศัพท์ eSIM Android ทุกรุ่น และเป็นทางสำรองที่เชื่อถือได้ที่สุด

### เส้นทางเมนู Android แยกตามแบรนด์

ตารางด้านบนพาคุณไปถึงแล้ว ส่วนนี้คือรายละเอียดเบื้องหลัง แต่ละแบรนด์เรียกฟีเจอร์เดียวกันต่างกันเล็กน้อย และเส้นทางก็ขยับไปบ้างระหว่างเวอร์ชันซอฟต์แวร์

| แบรนด์และซอฟต์แวร์ | เส้นทางแบบละเอียด | หมายเหตุ |
|---|---|---|
| Samsung (One UI 7) | Settings > Connections > SIM Manager > **Add eSIM** | One UI 6.0 เปลี่ยน "SIM card manager" เป็น "SIM Manager"; One UI 5.x รุ่นเก่ายังใช้ "SIM card manager" |
| Samsung (One UI 5) | Settings > Connections > **SIM card manager** > Add mobile plan | ป้ายเปลี่ยนเป็น "Add mobile plan" ไม่ใช่ "Add eSIM" |
| Google Pixel (Android 15) | Settings > Network & internet > **SIMs** > Add SIM > Download a SIM instead? > Next | Pixel เป็นแบรนด์ที่สม่ำเสมอที่สุด — เส้นทางแทบไม่เปลี่ยนตั้งแต่ Android 12 |
| Google Pixel (Android 12) | Settings > Network & internet > Mobile network > **Add eSIM** | Pixel รุ่นเก่าใช้ป้าย "Add eSIM" แบบง่ายกว่าก่อนมีหน้า SIMs |
| Xiaomi / Redmi / POCO (HyperOS) | Settings > **SIM cards & mobile networks** > eSIM > Add eSIM | eSIM มีเฉพาะรุ่น global บางรุ่น (Xiaomi 13/13T, 14/14T, 15); Redmi/POCO ส่วนใหญ่ไม่มีฮาร์ดแวร์ eSIM |
| OnePlus (OxygenOS 14) | Settings > Mobile network > **SIM & network** > Add eSIM | OxygenOS 13 ซ่อนไว้ใต้ "Wi-Fi & network"; 14 จัดใหม่เป็น "Mobile network" |
| Motorola | Settings > Network & internet > Mobile network > **Add carrier** | มีเฉพาะรุ่นที่เลือก (razr และ Edge บางรุ่น) รองรับ eSIM; Moto G หลายรุ่นไม่มี |
| Honor / Oppo / Vivo / Realme | ค้นหา "eSIM" ใน Settings | รองรับไม่สม่ำเสมอและขึ้นกับรุ่น — ตรวจ[รายการความเข้ากันได้ของ eSIM](/compatibility/) ก่อนสมมติว่ามี |

ถ้าไม่เห็นทางใดเลย ให้ค้นหา "eSIM" ในแถบค้นหาของ Settings ถ้าไม่มีอะไรโผล่ขึ้นมา เครื่องแทบเป็นไปได้สูงว่าไม่มีฮาร์ดแวร์ eSIM — รายละเอียดระดับรุ่นเต็มอยู่ใน[คู่มือแบรนด์ Android ที่รองรับ eSIM](/faq/android-esim-other-brands-deep-guide/) และ[รายการอุปกรณ์ฉบับเต็ม](/compatibility/)

## หาที่อยู่ SM-DP+ และรหัสเปิดใช้งานได้ที่ไหน

การกรอกเองต้องใช้ข้อความสองชุดที่อยู่ในอีเมลยืนยันหรือแอปของผู้ให้บริการ

| ผู้ให้บริการ | ดูได้ที่ไหน |
|---|---|
| Roami | อีเมลยืนยัน — "Manual installation details" / "SM-DP+ Address" |
| Airalo | แอป: แพ็กเกจ > Details > Manual installation |
| Holafly | อีเมลยืนยัน — "Manual installation" |
| Nomad | แอป: eSIM details > Manual install |
| Google Fi | ไม่รองรับการกรอกเอง — ใช้แอป Fi |
| US Mobile | แอป: Account > eSIM > Manual activation code |
| T-Mobile (US) | อีเมลยืนยันหรือแอป T-Mobile |

แคปหน้าจอเหล่านี้ไว้ก่อนบิน — ถ้าไม่มี Wi-Fi ตอนลงเครื่อง คุณจะหาดูไม่ได้

## ผู้ให้บริการรายใหญ่แต่ละรายส่งมอบ eSIM อย่างไร

คำว่า "เปิดใช้งาน" หมายถึงสิ่งที่ต่างกันเล็กน้อยขึ้นอยู่กับว่าใครขายแพ็กเกจให้คุณ นี่คือสิ่งที่ควรคาดหวังจากผู้ให้บริการ eSIM ท่องเที่ยวทั้งห้ารายที่พบบ่อยที่สุด เพื่อให้คุณรู้ว่าในกล่องจดหมายมีอะไรและจะติดตั้งอย่างไร

| ผู้ให้บริการ | วิธีติดตั้ง | สิ่งที่มาในอีเมล | เวลาส่งมอบโดยทั่วไป |
|---|---|---|---|
| Roami | แตะเดียวในแอป **หรือ** QR code / กรอกเอง | QR code พร้อมบล็อก "manual installation" (ที่อยู่ SM-DP+ + รหัสเปิดใช้งาน) | ทันที — มักไม่เกิน 2 นาที |
| Airalo | แตะเดียวในแอป **หรือ** QR จากในแอป | ใบเสร็จสั่งซื้อ + คำแนะนำติดตั้ง; QR อยู่ในแอปใต้ My eSIMs > Details | ทันที (QR ถูกสร้างบนหน้าแพ็กเกจ) |
| Holafly | แตะเดียวในแอป **หรือ** QR ในอีเมล | QR code พร้อมรายละเอียดแพ็กเกจข้อมูลไม่จำกัด | ทันที; หลายแพ็กเกจเปิดใช้งานอัตโนมัติทันทีที่เชื่อมต่อเครือข่ายพันธมิตร |
| Nomad | แตะเดียวในแอป **หรือ** QR / กรอกเอง | QR code + รหัสเปิดใช้งาน | ทันที โดยบางแพ็กเกจเริ่มนับความถูกต้องเมื่อใช้ครั้งแรก |
| Saily | ติดตั้งผ่านแอปเท่านั้น (แอป Saily) | ใบเสร็จ + ลิงก์เปิดแอป Saily | ทันที — โปรไฟล์ถูกส่งผ่านแอป ไม่ใช่ QR |

รูปแบบร่วม: ทั้งห้ารายส่ง QR หรือโปรไฟล์แทบจะทันที และวิธีติดตั้งที่เร็วที่สุดคือแอปของผู้ให้บริการเสมอ ความต่างคือ QR อยู่ *ที่ไหน* (อีเมล vs แอป) และนาฬิกาของแพ็กเกจเริ่มนับ *เมื่อไร* (ตอนติดตั้ง vs ตอนเชื่อมต่อครั้งแรก) ถ้าคุณยังลังเล Roami ส่งอีเมลมาพร้อมทั้ง QR และข้อความสำหรับกรอกเอง ซึ่งเป็นการตั้งค่าที่อภัยผู้ใช้มือใหม่ได้มากที่สุด

## เปิดใช้งานผ่านแอปผู้ให้บริการ

ผู้ให้บริการอย่าง Roami, Airalo และ Holafly ให้คุณข้าม QR ไปได้เลย ดาวน์โหลดแอป เปิดแพ็กเกจที่ซื้อไว้ แตะ **Install** หรือ **Activate** แล้วอนุญาตให้โทรศัพท์เพิ่มแพ็กเกจเซลลูลาร์ ขั้นตอนเหมือนกันทั้งบน iPhone และ Android และเป็นเส้นทางที่สะอาดที่สุดสำหรับมือใหม่ เพราะแอปสแกนหน้าจอตัวเองไม่ได้

## คุณควรใช้วิธีเปิดใช้งาน eSIM แบบไหน?

คุณมีทางเข้าสามทาง และไม่ใช่ทุกสถานการณ์ที่ใช้แทนกันได้ เลือกตามบริบท

| วิธี | เหมาะที่สุดเมื่อ | ระวัง |
|---|---|---|
| แอปผู้ให้บริการ (แตะเดียว) | คุณเป็นมือใหม่ที่อยากลุ้นน้อยที่สุด | ต้องติดตั้งแอปและล็อกอินไว้ก่อนออกจาก Wi-Fi ที่ดี |
| QR code | code อยู่บนเครื่องอื่นหรือกระดาษที่พิมพ์แล้ว | สแกน code บนหน้าจอโทรศัพท์เครื่องเดียวกันไม่ได้; แสงน้อยทำให้ลำบาก |
| กรอกเอง | QR เสียหาย หรืออยู่บนเครื่องที่กำลังจะเปิดใช้งาน | ข้อความ SM-DP+ ยาวและแยกตัวพิมพ์ใหญ่เล็ก — วางเท่านั้น อย่าพิมพ์ใหม่ |

คำแนะนำของเรา: ใช้เส้นทางแอปแตะเดียวของผู้ให้บริการสำหรับ eSIM ตัวแรกของคุณ และเก็บแคปหน้าจอ *ทั้ง* QR และข้อความสำหรับกรอกเองไว้เป็นสำรอง แอปเร็วที่สุด แต่ข้อความกรอกเองคือสิ่งเดียวที่จะไม่ทำให้คุณผิดหวังเมื่อทุกอย่างอื่นพัง

## วิธียืนยันว่าเปิดใช้งานสำเร็จ

อย่าเชื่อข้อความ "Cellular Setup Complete" เพียงอย่างเดียว ตรวจสามอย่าง:

1. **แถบสถานะ** — คุณเห็นขีดสัญญาณ (และชุดที่สองถ้าเปิดสองสาย)
2. **Settings** — สาย eSIM แสดง "On" หรือ "Active" ไม่ใช่ "No Service"
3. **ทดสอบจริง** — ปิด Wi-Fi ตั้ง eSIM เป็นสายข้อมูล แล้วโหลดหน้าเว็บ

ให้เวลาสูงสุดสองนาทีในการลงทะเบียนกับเครือข่ายท้องถิ่น ถ้ายังขึ้น "Searching" ดูคำแนะนำแก้ปัญหาด้านล่าง

## การเปิดใช้งานจริงใช้เวลานานแค่ไหน?

สั้น ๆ: การ *ดาวน์โหลด* ใช้เวลาไม่ถึงสองนาที แต่ *การเชื่อมต่อครั้งแรก* อาจใช้เวลาสูงสุด 15 นาทีหลังคุณลงเครื่อง สองอย่างนี้เป็นคนละเรื่องกัน และผู้คนมักสับสน

| ขั้นตอน | เกิดอะไรขึ้น | เวลาโดยทั่วไป |
|---|---|---|
| ส่งมอบ QR / โปรไฟล์ | ระบบของผู้ให้บริการสร้าง eSIM และส่งอีเมลให้คุณ | วินาทีถึง ~15 นาทีเมื่อระบบหนาแน่น |
| ดาวน์โหลดโปรไฟล์ | โทรศัพท์ของคุณดึงโปรไฟล์จากเซิร์ฟเวอร์ SM-DP+ | 30–60 วินาที สูงสุด 2 นาที |
| ลงทะเบียนเครือข่ายครั้งแรก | เมื่อถึงแล้ว โทรศัพท์สแกนเครือข่ายท้องถิ่นและเจรจากับผู้ให้บริการพันธมิตร | 2–15 นาที มักไม่เกิน 5 |
| ข้อมูลไหล | คุณโหลดหน้าเว็บโดยเปิด Data Roaming | ทันทีเมื่อลงทะเบียนแล้ว |

ทำไมบางผู้ให้บริการลงทะเบียนช้ากว่าคนอื่น? สามเหตุผล **ผู้ให้บริการรายเล็ก provisioning เป็นชุด** — โปรไฟล์ของคุณจะยัง "รออยู่" จนกว่าระบบฝั่งหลังบ้านประมวลผล **เครือข่ายพันธมิตรแน่น** — ลงสนามบินที่พลุกพล่านตอน 18.00 น. แปลว่าโทรศัพท์คุณเป็นหนึ่งในหลายพันเครื่องที่ลงทะเบียนพร้อมกัน และ **บางแพ็กเกจเริ่มนาฬิกาเมื่อเชื่อมต่อครั้งแรก** การจับมือกับเครือข่ายจึงถูกเลื่อนไปจนมีการใช้ข้อมูลครั้งแรกโดยตั้งใจ ทั้งหมดนี้ไม่ใช่ความผิดพลาด — เป็นแค่ความต่างระหว่าง "ติดตั้งแล้ว" กับ "ใช้งานจริง"

## ข้อผิดพลาดที่ทำให้การเปิดใช้งาน eSIM พัง

| ข้อผิดพลาด | ทำไมถึงพัง | วิธีแก้ |
|---|---|---|
| สแกนด้วยแอป Camera | จับรูป code ได้แต่ไม่ติดตั้งอะไรเลย | ทำผ่าน Settings > Add eSIM เท่านั้น |
| เปิดใช้งานบน Wi-Fi อ่อน | การดาวน์โหลดขาดกลางคันและโปรไฟล์เสียหาย | ติดตั้งที่บ้านก่อนไปสนามบิน |
| ลบ eSIM เพื่อ "รีเฟรช" | ทำลายโปรไฟล์และข้อมูลที่เหลืออย่างถาวร | อย่าลบ เว้นแต่แพ็กเกจหมดอายุแล้ว |
| รอลงเครื่องแล้วค่อยติดตั้ง | ไม่มี Wi-Fi ให้ดาวน์โหลดโปรไฟล์ | ติดตั้งก่อนออกเดินทาง; จะยังไม่ทำงานจนกว่าคุณจะถึง |
| ลืมเปิด Data Roaming | สัญญาณเต็ม แต่อินเทอร์เน็ตเป็นศูนย์ | เปิด Data Roaming สำหรับ eSIM ท่องเที่ยวหลังลงเครื่อง |
| ลืมรหัสผ่าน | การติดตั้งค้างกลางทาง | ยืนยันรหัสผ่านก่อนเริ่ม |
| สแกน code บนหน้าจอตัวเอง | กล้องเล็งตัวเองไม่ได้ | บันทึกลงรูปภาพแล้วใช้ "เลือกรูปภาพ" หรือใช้การกรอกเอง |

## ต้องทำอย่างไรเมื่อการเปิดใช้งาน eSIM ติดขัด

ถ้าคุณค้างที่ "Activating…" หรือ "Searching" ให้ไล่ขั้นบันไดนี้จากบนลงล่าง — แก้การเปิดใช้งานที่ค้างได้เกือบทั้งหมดโดยไม่ต้องติดต่อฝ่ายสนับสนุน

1. **รีสตาร์ทโทรศัพท์** ฟังดูง่ายเกินไป แต่การบูตใหม่ทำให้การจับมือกับเครือข่ายเริ่มใหม่ และแก้โปรไฟล์ที่ค้างได้ครึ่งหนึ่งของเคส
2. **เปิดโหมดเครื่องบิน 30 วินาที แล้วปิด** บังคับให้โทรศัพท์สแกนเครือข่ายท้องถิ่นใหม่ตั้งแต่ต้น
3. **สแกน QR ใหม่** ลบโปรไฟล์ *pending* (ที่ยังไม่ active) แล้วเพิ่มใหม่บนเครือข่ายที่แรงกว่า อย่าลบแพ็กเกจที่ใช้งานได้อยู่แล้วเด็ดขาด
4. **พิมพ์ที่อยู่ SM-DP+ ให้ตรงเป๊ะ** การกรอกเองแยกตัวพิมพ์ใหญ่เล็กและแยกช่องว่าง — ตัวอักษรผิดตัวเดียวพาโทรศัพท์ไปเซิร์ฟเวอร์ที่ตายแล้ว วางเท่านั้น อย่าพิมพ์ใหม่
5. **เปิด Data Roaming สำหรับ eSIM ท่องเที่ยว** "No Service" ทั้งที่ขีดสัญญาณเต็มแทบทั้งหมดเป็นเพราะเรื่องนี้
6. **ย้ายไป Wi-Fi ที่เสถียร** ถ้าการดาวน์โหลดค้างซ้ำ ๆ คุณอาจมีโปรไฟล์ครึ่ง ๆ กลาง ๆ ที่ติดตั้งใหม่ได้สะอาดเฉพาะบนการเชื่อมต่อที่ดี

ถ้าข้อผิดพลาดเป็นรหัสเฉพาะ — "Invalid QR code," "Cellular Plan Cannot Be Added," ปัญหา APN — นั่นคือเรื่องรายข้อผิดพลาด และวิธีแก้ (พร้อมค่า APN) อยู่ใน[คู่มือแก้ปัญหา eSIM เชิงลึก](/faq/esim-deep-troubleshooting-guide-2026/)

## เปิดใช้งานบนแท็บเล็ต Android หรือพอร์เทเบิลฮอตสปอต

eSIM ไม่ได้มีไว้เฉพาะโทรศัพท์ **แท็บเล็ต Android รุ่นเซลลูลาร์** — เช่น Samsung Galaxy Tab ซีรีส์ S หรือ Lenovo รุ่นเซลลูลาร์ — ใช้เส้นทางเดียวกับรุ่นโทรศัพท์พี่น้องเป๊ะ: Settings > Connections (หรือ Network & internet) > SIM Manager > Add eSIM ถ้าแท็บเล็ตของคุณมี EID จาก `*#06#` แปลว่าใช้ eSIM ได้

**พอร์เทเบิลฮอตสปอต (MiFi)** มีความหลากหลายกว่า ฮอตสปอตท่องเที่ยวส่วนใหญ่ยังใช้ซิมการ์ดแบบ physical แต่มีรุ่นพรีเมียมบางรุ่น — เช่นซีรีส์ Netgear Nighthawk M6 และบางรุ่นของ ZTE และ GlocalMe — รองรับ eSIM ถ้าคุณแชร์เน็ตให้ทั้งครอบครัว ฮอตสปอต eSIM เป็นทางแก้ที่เรียบร้อย แม้ว่าโดยปกติคุณจะได้ความยืดหยุ่นมากกว่า (และแพ็กเกจถูกกว่า) ถ้าใส่ eSIM ไว้ในโทรศัพท์เครื่องหนึ่งแล้วแชร์ฮอตสปอตของมันแทน

**iPad และ Apple Watch** รุ่นเซลลูลาร์ของ Apple มีกติกาเป็นของตัวเอง — Watch สะท้อนสายของโทรศัพท์แทนที่จะใช้ eSIM ท่องเที่ยวโดยตรง เรื่องนี้มีอยู่ใน[คู่มือ eSIM iPad และ Apple Watch](/faq/ipad-apple-watch-esim-support-guide/)

## ความเชื่อผิด ๆ ที่พบบ่อยเรื่องการเปิดใช้งาน eSIM

สิ่งที่ผู้คนเชื่อเกี่ยวกับการเปิดใช้งานแต่ไม่จริง:

- **"ฉันต้องโทรหาผู้ให้บริการเพื่อเปิดใช้งาน"** ไม่ใช่ — การติดตั้งโปรไฟล์ไม่ต้องโทรใด ๆ คุณติดต่อผู้ให้บริการเฉพาะเพื่อ *ออกโปรไฟล์ใหม่* หลังจากลบไปหรือเปลี่ยนเครื่องเท่านั้น
- **"ฉันต้องอยู่ที่ปลายทางถึงจะเปิดใช้งานได้"** คุณติดตั้งที่บ้านได้ แพ็กเกจจะทำงานจริงเมื่อโทรศัพท์ของคุณเชื่อมต่อเครือข่ายที่ปลายทางเท่านั้น
- **"การลบ eSIM รีเซ็ตแพ็กเกจของฉัน"** การลบทำลายโปรไฟล์อย่างถาวร — และ QR code ใช้ได้ครั้งเดียว คุณจะต้องมีแพ็กเกจใหม่ทั้งหมด
- **"ฉันแชร์ eSIM หนึ่งตัวข้ามสองเครื่องได้"** ไม่ได้ — โปรไฟล์อยู่บนเครื่องเดียวในเวลาหนึ่ง คุณมัก *ย้าย* มันระหว่างเครื่องได้ แต่รันโปรไฟล์เดียวกันบนสองเครื่องพร้อมกันไม่ได้
- **"eSIM ช้ากว่า physical SIM"** ข้อมูลรับรองเหมือนกัน ไม่มีความต่างด้านความเร็ว ความเร็วข้อมูลของคุณมาจากเครือข่ายและแพ็กเกจ ไม่ใช่รูปแบบซิม

## หัวข้ออื่น ๆ อยู่ในหน้าของตัวเอง

เพื่อให้คู่มือนี้โฟกัส หัวข้อที่เกี่ยวข้องเหล่านี้มีคู่มือเฉพาะของตัวเอง:

- **แก้ปัญหาข้อผิดพลาดเฉพาะ** ("Invalid QR code," ค้าง "Activating," "No Service," การตั้งค่า APN) → [คู่มือแก้ปัญหา eSIM เชิงลึก](/faq/esim-deep-troubleshooting-guide-2026/)
- **ย้าย eSIM ไปโทรศัพท์ใหม่** (iOS ไป iOS, Android ไป Android, ข้ามแพลตฟอร์ม) → [ย้าย eSIM ระหว่าง iPhone และ Android](/faq/how-to-transfer-esim-between-iphone-and-android/)
- **ใช้สองสายพร้อมกัน** (dual SIM / DSDS) → [ศูนย์รวมความเข้ากันได้ eSIM ของ iPhone](/faq/iphone-11-esim-compatible/)
- **eSIM บน iPad และ Apple Watch** → [คู่มือ eSIM iPad และ Apple Watch](/faq/ipad-apple-watch-esim-support-guide/)
- **ผู้ให้บริการและอุปกรณ์ใดรองรับ eSIM** → [รายการความเข้ากันได้ฉบับเต็ม](/compatibility/)

## คำถามที่พบบ่อย

**มีค่าธรรมเนียมเปิดใช้งาน eSIM ไหม?**
ไม่มี ผู้ให้บริการไม่คิดค่าใช้จ่ายสำหรับการสแกนและติดตั้งโปรไฟล์ — คุณจ่ายเฉพาะแพ็กเกจข้อมูลเท่านั้น ใครก็ตามที่เก็บ "ค่าธรรมเนียมเปิดใช้งาน" ถือว่าอยู่นอกข้อปฏิบัติปกติ

**เปิดใช้งาน eSIM ก่อนเดินทางได้ไหม?**
ได้ และคุณควรทำ ติดตั้งที่บ้านบน Wi-Fi ที่เชื่อถือได้ แพ็กเกจจะยังไม่ทำงานจนกว่าโทรศัพท์ของคุณจะเชื่อมต่อเครือข่ายที่ปลายทาง แค่อย่าลืมเปิด Data Roaming หลังลงเครื่อง

**การเปิดใช้งาน eSIM ใช้เวลานานแค่ไหน?**
การดาวน์โหลดโปรไฟล์ใช้เวลาไม่ถึงสองนาที การเชื่อมต่อเครือข่ายท้องถิ่นครั้งแรกอาจใช้เวลาสูงสุด 10–15 นาทีขึ้นอยู่กับสัญญาณ ถ้าเกินนั้น ให้รีสตาร์ทโทรศัพท์

**ต้องมี Wi-Fi เพื่อเปิดใช้งาน eSIM ไหม?**
สำหรับการดาวน์โหลดโปรไฟล์ครั้งแรก ใช่ — โปรไฟล์มาจากเซิร์ฟเวอร์ SM-DP+ ที่ปลอดภัยของผู้ให้บริการ และสัญญาณเซลลูลาร์ที่อ่อนจะดึงมาได้ไม่น่าเชื่อถือ ติดตั้งบน Wi-Fi บ้านก่อนออกเดินทาง แล้วแพ็กเกจจะหลับใหลจนคุณลงเครื่อง

**เก็บ eSIM ได้กี่ตัวในโทรศัพท์ และสลับใช้ระหว่างกันได้ไหม?**
โทรศัพท์สมัยใหม่ส่วนใหญ่เก็บโปรไฟล์ eSIM ได้แปดตัวขึ้นไป แต่ครั้งละหนึ่งหรือสองตัวเท่านั้นที่ *active* ได้ คุณสลับโปรไฟล์ที่ active ได้จากหน้า Settings เดียวกับที่ใช้เพิ่ม — สะดวกมากสำหรับทริปหลายประเทศ

**QR code กับการกรอกเองต่างกันอย่างไร?**
การสแกน QR เป็นเส้นทางมาตรฐาน — เร็วกว่าและพิมพ์ผิดยากกว่า การกรอกเอง (ที่อยู่ SM-DP+ + รหัสเปิดใช้งาน) เป็นทางสำรองที่ใช้ได้เมื่อกล้องหรือ code ใช้ไม่ได้

**ใช้ eSIM แบบ data-only โทรและส่งข้อความได้ไหม?**
eSIM ท่องเที่ยวแบบ data-only มีอินเทอร์เน็ตแต่ไม่มีเบอร์โทรศัพท์ จึงโทรแบบดั้งเดิมหรือส่ง SMS ไม่ได้ คุณยังติดต่อได้ผ่านเบอร์บ้าน (ผ่าน Wi-Fi Calling) ขณะที่ eSIM ท่องเที่ยวดูแลข้อมูล — นักเดินทางส่วนใหญ่ใช้แบบนี้

**eSIM ของฉันค้างที่ "Activating" — ควรรอนานแค่ไหน?**
สูงสุด 10–15 นาทีหลังลงเครื่อง โดยเฉพาะสนามบินที่พลุกพล่าน ถ้ายังค้างหลังจากนั้น ให้รีสตาร์ทโทรศัพท์ เปิดโหมดเครื่องบิน 30 วินาที หรือลบโปรไฟล์ pending แล้วสแกนใหม่บน Wi-Fi ที่แรงกว่า

**ต้องเปิด Data Roaming สำหรับ eSIM ท่องเที่ยวไหม?**
ใช่ — eSIM ท่องเที่ยวเข้าถึงเครือข่ายผ่านผู้ให้บริการพันธมิตร Data Roaming จึงต้องเปิดสำหรับสายนั้น อย่างนี้ไม่เกิดค่า roaming เพิ่ม เป็นแค่กลไกการเชื่อมต่อ

**ที่อยู่ SM-DP+ หมายถึงอะไร?**
SM-DP+ (Subscription Manager – Data Preparation Plus) คือเซิร์ฟเวอร์ที่ปลอดภัยซึ่งส่งโปรไฟล์ eSIM ให้คุณ ในการกรอกเอง มันบอกโทรศัพท์ของคุณว่าจะดาวน์โหลดโปรไฟล์จากที่ไหน

**ใช้ eSIM ท่องเที่ยวกับ Wi-Fi Calling ได้ไหม?**
ได้ — Wi-Fi Calling เป็นของ *สายบ้าน* ของคุณ ไม่ใช่ eSIM ท่องเที่ยว เปิด Wi-Fi Calling ไว้สำหรับเบอร์บ้านและมันจะทำงานผ่านข้อมูลของ eSIM ท่องเที่ยว (หรือ Wi-Fi ใดก็ได้) ทำให้คุณติดต่อได้โดยไม่มีค่า roaming

**ถ้าเปิดใช้งานแล้วไม่มีสัญญาณเลยต้องทำอย่างไร?**
ไม่มีขีดสัญญาณเลยมักแปลว่าคุณอยู่นอกพื้นที่ครอบคลุมของเครือข่ายพันธมิตร หรือโทรศัพท์ยังไม่ได้ลงทะเบียน เปิดโหมดเครื่องบิน 30 วินาที ยืนยันว่า Data Roaming เปิดสำหรับ eSIM ท่องเที่ยว และออกไปข้างนอกถ้าคุณอยู่ในอาคาร "No Service" ที่ต่อเนื่องเป็นปัญหา APN หรือ provisioning — ดู[คู่มือแก้ปัญหาเชิงลึก](/faq/esim-deep-troubleshooting-guide-2026/)
