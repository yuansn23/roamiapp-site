## 安裝與啟用土耳其 eSIM 有什麼不同？

安裝與啟用是兩個獨立的步驟。安裝是把設定檔（profile）下載到手機的 eUICC 晶片上；啟用則是讓該設定檔在土耳其的行動網路上註冊。把兩者混淆，是旅客以為 eSIM 壞掉了（其實只是休眠）最常見的原因。

### 土耳其 eSIM 安裝做的是什麼

安裝會從供應商的 SM-DP+ 伺服器下載設定檔到手機內的 eUICC 晶片。安裝完成後，eSIM 會出現在「設定」中作為次要門號，並擁有 ICCID 與 APN 值。

安裝不會讓 eSIM 連上任何網路。已安裝但未開啟數據漫遊的 eSIM 會保持閒置。

### 土耳其 eSIM 啟用做的是什麼

啟用是設定檔在土耳其行動網路上註冊的那一刻。這發生在你抵達土耳其後，為 eSIM 門號開啟數據漫遊的時候。手機會搜尋合作電信——Turkcell、Vodafone Turkey 或 Türk Telekom——並建立數據連線。

註冊通常需要 2–5 分鐘。之後電信名稱會出現在狀態列，數據開始流動。

### 土耳其 eSIM 安全啟用流程表

| 步驟 | 時機 | 地點 | 要做的事 |
|---|---|---|---|
| 安裝 | 出發前 | 家中 Wi-Fi | 掃描 QR code，將門號命名為「Turkey」 |
| 設定 | 出發前 | 家中 | 原本 SIM 負責語音與簡訊，土耳其 eSIM 負責行動數據 |
| 保持漫遊關閉 | 直到落地 | — | 不要開啟數據漫遊 |
| 啟用 | 落地後 | 土耳其機場 | 為土耳其 eSIM 開啟數據漫遊 |
| 驗證 | 啟用後 | 機場 | 開啟地圖或瀏覽器測試 |

### 為什麼土耳其 eSIM 的啟用時機很重要

如果在家中就開啟數據漫遊，eSIM 可能會連上你所在國家的合作網路，在上飛機前就消耗掉你的土耳其數據。有些供應商會防止這種情況，有些則不會。落地前請保持漫遊關閉。

## 土耳其 eSIM 安裝前檢查

購買或安裝任何土耳其 eSIM 之前，先執行這些檢查。它們可以預防最常見的啟用失敗：沒有 EID、電信鎖、沒有空閒的 eSIM 插槽，以及安裝時 Wi-Fi 不穩定。

### 先檢查 EID

**iPhone：** 設定 → 一般 → 關於本機 → 捲動至「EID」。如果看到 32 位數字，你的裝置支援 eSIM。

**Android：** 設定 → 關於手機 → 狀態資訊 → 「EID」。有些廠商將它放在設定 → 網路與網際網路 → SIM 卡裡。

### 確認手機未鎖電信

**iPhone：** 設定 → 一般 → 關於本機 → 「電信鎖（Carrier Lock）」。應顯示「無 SIM 卡限制（No SIM restrictions）」。

**Android：** 設定 → 關於手機 → SIM 鎖，或插入非原電信的 SIM 卡，看看裝置是否接受。

### 確認還有空閒的插槽

大多數手機支援一或兩個啟用中的 eSIM 設定檔。如果你已經有一個啟用中的 eSIM，可能需要停用其中一個門號才能再加入新的。

**iPhone 13 及更新機型：** 支援兩個啟用中的 eSIM。

**iPhone XS 至 iPhone 12：** 一個 eSIM 加一張實體 SIM。

**大多數 Android 手機：** 一個 eSIM 加一張實體 SIM。

### 穩定的 Wi-Fi 與離線保存的 QR code

安裝需要穩定的網路連線。請使用家中 Wi-Fi，不要使用行動熱點或需要登入門戶頁面的公共 Wi-Fi。開始之前，先把 QR code 的電子郵件或 PDF 離線保存。如果安裝失敗需要重試，你不會想依賴能否開啟電子郵件。

### 土耳其 eSIM 安裝前檢查清單

- [ ] EID 存在
- [ ] 電信已解鎖
- [ ] 有空閒的 eSIM 插槽
- [ ] Wi-Fi 連線穩定
- [ ] QR code 已離線保存
- [ ] APN 值已離線保存
- [ ] 手機電量超過 50%

## 土耳其 eSIM 的 QR Code 安裝

QR code 安裝是加入土耳其 eSIM 最快的方式。手機會聯繫供應商的 SM-DP+ 伺服器，並將設定檔下載到 eUICC 晶片。在穩定的 Wi-Fi 下，整個過程約 60 秒。

### iPhone 上的 QR 安裝

1. 開啟**設定**。
2. 點選**行動數據**或**行動服務**。
3. 點選**加入數據方案**或**加入 eSIM**。
4. 選擇**使用 QR Code**。
5. 掃描供應商電子郵件中的 QR code。
6. 手機聯繫 SM-DP+ 伺服器並下載設定檔。
7. 點選**加入**以安裝。
8. 將門號命名為「Turkey」。
9. 將它設為預設的**行動數據**門號。
10. 暫時不要開啟數據漫遊。

### Android 上的 QR 安裝

1. 開啟**設定**。
2. 點選**網路與網際網路** → **SIM 卡**。Samsung 機型：**連接** → **SIM 卡管理員**。
3. 點選**加入 eSIM**或**下載 SIM**。
4. 選擇**使用 QR Code**。
5. 掃描 QR code。
6. 手機聯繫 SM-DP+ 伺服器並下載設定檔。
7. 確認下載並啟用新門號。
8. 選擇 eSIM 作為**行動數據**。
9. 暫時不要開啟數據漫遊。

### 土耳其 eSIM 安裝後應該看到的畫面

- 設定檔下載時的進度指示。
- 顯示電信名稱與方案細節的確認畫面。
- eSIM 出現在「設定」中作為次要門號。
- 在 eSIM 詳細資訊中可以看到 ICCID。
- APN 欄位可能已預先填入。

### 土耳其 eSIM 安裝後不應該出現的訊息

- 「電信不受支援（Carrier not supported）」。
- 「不支援 eSIM（eSIM not supported）」。
- 空白畫面或卡住的進度指示。
- 「已被使用（Already used）」或「已過期（Expired）」。

### 土耳其 eSIM 的 QR Code 單次使用限制

QR code 是一次性的憑證。一旦設定檔被下載到某部裝置的 EID，同一個 QR code 就無法再安裝到其他裝置。如果你看到「已被使用」或「已過期」，請聯繫供應商取得替換。不要把恢復原廠設定當作第一個解法——恢復原廠設定沒有幫助，還會清除你的設定。

## 土耳其 eSIM 手動安裝與 SM-DP+ 資訊輸入

當 QR code 無法掃描或相機不可用時，手動安裝是備案。你需要供應商訂單確認信中的 SM-DP+ 位址與啟用碼。

### iPhone 上的手動安裝

1. 開啟**設定** → **行動數據**。
2. 點選**加入 eSIM**。
3. 點選**手動輸入資訊**。
4. 輸入供應商提供的 **SM-DP+ 位址**與**啟用碼**。
5. 點選**下一步**並確認。
6. 將門號命名為「Turkey」並設為行動數據。

### Android 上的手動安裝

1. 開啟**設定** → **網路與網際網路** → **SIM 卡**。
2. 點選**加入 eSIM**。
3. 點選**需要協助嗎？**或**手動輸入**。
4. 輸入供應商提供的啟用碼。
5. 確認並安裝。
6. 啟用該門號並選擇它作為行動數據。

### 在哪裡找到 SM-DP+ 位址

SM-DP+ 位址是保存你 eSIM 設定檔的伺服器。啟用碼是授權下載的一次性權杖。兩者都與你的訂單和裝置的 EID 綁定。

如果供應商的電子郵件沒有顯示 SM-DP+ 位址，請查看訂單確認信或支援頁面。[GSMA SGP.22 eSIM 規範](https://www.gsma.com/esim/)定義了這種供應機制的運作方式。

### 土耳其 eSIM 的 QR Code 格式

符合 GSMA 標準的 eSIM QR code 包含如下字串：

`LPA:1$sm-dp-plus.example.com$ACTIVATION-CODE`

- **LPA** — Local Profile Assistant，管理 eSIM 設定檔的軟體元件。
- **1** — 版本號。
- **SM-DP+ 位址** — 伺服器位址。
- **啟用碼** — 一次性權杖。

如果你掃描的 QR code 不符合這個格式，安裝將會失敗。

### 土耳其 eSIM 手動安裝的錯誤代碼

| 錯誤 | 原因 | 解法 |
|---|---|---|
| 「啟用碼無效」 | 代碼錯誤或已過期 | 檢查訂單確認信 |
| 「無法連線伺服器」 | Wi-Fi 問題或 SM-DP+ 當機 | 換一個 Wi-Fi 重試 |
| 「設定檔已安裝」 | QR code 已被使用 | 聯繫供應商 |
| 「EID 無法辨識」 | 裝置錯誤或 EID 不符 | 在設定中檢查 EID |

## 雙 SIM 設定

雙 SIM 設定是大多數落地後故障的根源。土耳其 eSIM 必須是數據門號，原本 SIM 必須處理語音與簡訊，且行動數據切換必須關閉。

### iPhone 的土耳其 eSIM 雙 SIM 設定

1. 開啟**設定** → **行動數據**。
2. 在**行動數據**下方，選擇**土耳其 eSIM**。
3. 在**預設語音門號**下方，選擇你的**原本 SIM**。
4. 將原本 SIM 的數據漫遊關閉。
5. 落地後為土耳其 eSIM 開啟數據漫遊。
6. 關閉「允許切換行動數據」。

### Android 的土耳其 eSIM 雙 SIM 設定

**Samsung：** 設定 → 連接 → SIM 卡管理員。選擇土耳其 eSIM 作為**行動數據**。選擇原本 SIM 作為**通話**與**簡訊**。關閉原本 SIM 的漫遊，開啟 eSIM 的漫遊。

**Google Pixel：** 設定 → 網路與網際網路 → SIM 卡。點選土耳其 eSIM 並啟用**行動數據**。點選原本 SIM 並停用**行動數據**與**漫遊**。機型專屬步驟請見 [Google 的 Pixel 說明中心](https://support.google.com/pixelphone)。

### 三個代價高昂的土耳其 eSIM 雙 SIM 錯誤

**把行動數據留在原本 SIM 上。** 你的原電信會對每一 MB 收取漫遊費。請確認土耳其 eSIM 是數據門號。

**忘記為 eSIM 開啟漫遊。** 旅遊 eSIM 是以漫遊設定檔的方式運作。未開啟漫遊時，它無法連上土耳其的網路。

**開啟「允許切換行動數據」。** 這會讓手機自動切換到訊號較好的門號。在土耳其，數據可能因此經由你的原本 SIM 傳送，觸發漫遊收費。

### 土耳其 eSIM 雙 SIM 設定矩陣

| 設定 | 原本 SIM | 土耳其 eSIM |
|---|---|---|
| 行動數據 | 關閉 | 開啟 |
| 數據漫遊 | 關閉 | 落地後開啟 |
| 語音與簡訊 | 開啟 | 關閉 |
| 允許切換行動數據 | 關閉 | 關閉 |
| Wi-Fi 通話 | 選用 | 不適用 |

## 為什麼 eSIM 需要 APN 設定？

APN 是土耳其 eSIM「有訊號格卻無法上網」最常見的原因。沒有正確的 APN，手機可以在網路上註冊並顯示滿格訊號，但數據不會流動。APN 值取決於你的 eSIM 供應商，而不是當地的土耳其電信。

### APN 實際上做什麼

APN 告訴手機行動數據要使用哪個閘道。沒有正確的 APN，手機可以在網路上註冊並顯示訊號格，但數據不會流動。這是「有訊號格卻無法上網」最常見的原因。

### 何時需要檢查土耳其 eSIM 的 APN

符合以下情況時檢查 APN：

- 手機顯示訊號格與電信名稱
- 看得到 LTE 或 5G 標示
- 網站與 App 無法載入
- 重新開機與切換飛航模式都沒有用

如果完全沒有訊號格，問題是網路註冊而非 APN。先試試手動選擇網路。

### iPhone 上的 APN 設定

1. 開啟**設定** → **行動數據**。
2. 選擇**土耳其 eSIM**。
3. 點選**行動數據網路**。如果看不到這個選單，表示 APN 由電信設定檔自動管理。
4. 輸入訂單確認信中的 APN 值。
5. 確認土耳其 eSIM 被選為數據門號。
6. 為 eSIM 開啟數據漫遊。
7. 切換飛航模式開關。

### Android 上的 APN 設定

1. 開啟**設定** → **網路與網際網路** → **SIM 卡**。
2. 選擇**土耳其 eSIM**。
3. 開啟**存取點名稱（APN）**。
4. 點選**新增**或**加號**。
5. 輸入名稱與供應商提供的 APN 值。
6. 使用者名稱與密碼留空，儲存後選擇該設定檔。
7. 為 eSIM 開啟行動數據與數據漫遊。
8. 切換飛航模式。

完整關機再重新開機，可以解決大多數網路註冊問題。落地後，手機可能還保留著先前的網路狀態。

### 步驟 5：嘗試手動選擇網路

**iPhone：** 設定 → 行動數據 → eSIM → 網路選擇 → 關閉自動 → 選擇 Turkcell、Vodafone TR 或 Türk Telekom。

**Android：** 設定 → 網路 → SIM 卡 → eSIM → 電信業者 → 手動搜尋。

逐一嘗試每個網路。Turkcell 的全國涵蓋範圍最廣。Vodafone 在特定沿海地區可能表現更好。詳見 [Turkcell、Vodafone 與 Türk Telekom 比較](/blog/turkcell-vodafone-turk-telekom-esim/)。

### 步驟 6：檢查土耳其 eSIM 的 APN

如果都沒有用，帶著你的 ICCID 與訂單編號聯繫客服。ICCID 是 eSIM 設定檔上的 19–20 位數字。一套附 24 小時真人客服、且可透過 Wi-Fi 聯繫的[土耳其 eSIM](/turkey-esim/)，能在自助步驟失敗時讓你找到真人求助。

## 常見問題：土耳其 eSIM 啟用、QR 與 APN

### 安裝與啟用土耳其 eSIM 有什麼不同？

安裝是把設定檔下載到 eUICC 晶片；啟用是讓設定檔在土耳其網路上註冊。出發前在 Wi-Fi 環境安裝，落地後開啟數據漫遊完成啟用。

### 如何在 iPhone 上安裝土耳其 eSIM？

設定 → 行動數據 → 加入數據方案，掃描 QR code，將門號命名為「Turkey」，設為行動數據，落地前保持漫遊關閉。機型專屬步驟請見 [Apple 官方 eSIM 支援文件](https://support.apple.com/en-us/HT209096)。

### 如何在 Android 上安裝土耳其 eSIM？

設定 → 網路與網際網路 → SIM 卡 → 加入 eSIM，掃描 QR code，啟用門號，選為行動數據。落地後開啟漫遊。

### 為什麼我的土耳其 eSIM 有訊號格卻無法上網？

三個最常見的原因是：數據門號錯誤、eSIM 漫遊未開啟、APN 空白或錯誤。請依照上方的判斷流程逐步處理。

### 土耳其 eSIM 應該使用哪個 APN？

APN 取決於你的 eSIM 供應商，而不是當地的土耳其電信。請查看訂單確認信。不要假設要使用 Turkcell 或 Vodafone 的 APN。

### QR code 顯示「已被使用」——該怎麼辦？

QR code 只能使用一次。請聯繫供應商取得替換。不要把恢復原廠設定當作第一個解法。

### 土耳其 eSIM 啟用需要多久？

在 Wi-Fi 環境安裝約需 60 秒。落地後的網路註冊通常需要 2–5 分鐘。

### 土耳其 eSIM 的 SM-DP+ 位址是什麼？

SM-DP+ 位址是保存你 eSIM 設定檔的伺服器，是安裝時手機聯繫的網域名稱或 IP 位址。啟用碼則是一次性權杖。

### 可以不用供應商 App 啟用土耳其 eSIM 嗎？

可以。啟用是透過手機的設定完成，不需要供應商 App。為 eSIM 門號開啟數據漫遊，等待 2–5 分鐘的網路註冊即可。

### 如果落地後土耳其 eSIM 無法連線怎麼辦？

檢查數據門號、開啟漫遊、重新開機、嘗試手動選擇網路、檢查 APN。如果都無效，聯繫客服。若供應商被封鎖，使用可透過 Wi-Fi 聯繫的客服。

### 土耳其 eSIM 手動選網時該選哪個網路？

鄉村地區、卡帕多奇亞與土耳其東部選 Turkcell。沿海度假區與伊斯坦堡選 Vodafone TR。城市與精打細算的旅行選 Türk Telekom。

### 刪除土耳其 eSIM 後可以重新安裝嗎？

只有當你有新的 QR code，或供應商支援 eSIM 轉移時才可以。原始 QR code 只能使用一次。如果供應商被 BTK 封鎖，你在土耳其境內無法申請新的 QR code。

### 沒有 QR code 也能啟用土耳其 eSIM 嗎？

可以，只要供應商提供 SM-DP+ 位址與啟用碼。QR code 無法掃描時就用手動安裝。兩種方式都是把同一個設定檔下載到同一個 eUICC 晶片。

## 最終檢查清單：土耳其 eSIM 啟用與疑難排解

使用這份最終檢查清單確認出發前的設定、為落地做準備，並在出問題時復原。BTK 封鎖讓出發前安裝對大多數供應商而言成為必要步驟。
