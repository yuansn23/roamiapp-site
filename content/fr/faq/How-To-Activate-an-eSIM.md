**L'essentiel en bref :**
Pour activer une eSIM, vous avez besoin d'un téléphone débloqué par l'opérateur, d'une connexion Wi-Fi stable et d'un code QR eSIM fourni par votre prestataire. Accédez aux paramètres cellulaires de votre téléphone, sélectionnez « Ajouter eSIM » ou « Ajouter un forfait de données », scannez le code QR et attendez 1 à 2 minutes que le profil numérique se télécharge et s'installe.

---

## Vérifications cruciales avant de commencer

Ne scannez pas votre code QR avant d'avoir vérifié ces trois exigences. Ne pas le faire est la cause n°1 des erreurs d'activation.

1. **Votre téléphone doit être débloqué par l'opérateur :** Si vous avez acheté votre téléphone via un contrat opérateur (comme AT&T ou Verizon), il pourrait être verrouillé sur leur réseau.
   * *Vérification iPhone :* Allez dans **Réglages > Général > Informations**. Faites défiler jusqu'à **Verrouillage opérateur**. Il doit indiquer **Aucune restriction SIM**.
2. **Vous avez besoin d'une connexion Wi-Fi stable :** Une eSIM est un téléchargement numérique. Vous ne pouvez pas l'activer à l'aide de vos données cellulaires habituelles car le téléphone a besoin d'une connexion Internet pour communiquer avec le serveur sécurisé de l'opérateur.
3. **N'utilisez pas votre application appareil photo :** Scannez toujours le code QR via le menu Réglages de votre téléphone, pas via l'application appareil photo standard.

## Comment activer une eSIM sur iPhone (iOS)

Apple a simplifié le processus eSIM dans les récentes mises à jour d'iOS. Suivez ces étapes précises pour installer votre profil.

1. **Étape 1 :** Allez dans **Réglages > Données cellulaires** (ou **Mobile** selon votre région).
2. **Étape 2 :** Appuyez sur **Ajouter eSIM** (ou **Ajouter un forfait de données** sur les anciennes versions d'iOS).
3. **Étape 3 :** Appuyez sur **Utiliser un code QR** en bas de l'écran.
4. **Étape 4 :** Positionnez le code QR dans le cadre de l'appareil photo.
5. **Étape 5 :** Une fois reconnu, appuyez sur **Continuer** et attendez le message « Configuration cellulaire terminée ».

Si vous ne pouvez pas scanner le code (par exemple, le code QR est sur le téléphone que vous utilisez), appuyez sur **Entrer les détails manuellement** en bas de l'écran de scan. Collez l'**adresse SM‑DP+** et le **code d'activation** fournis dans l'e-mail de votre opérateur.

## Comment activer une eSIM sur Android

Les menus Android varient légèrement selon le fabricant de l'appareil. Voici les chemins exacts pour les deux marques Android les plus populaires.

### Pour les appareils Samsung Galaxy :

1. **Étape 1 :** Allez dans **Réglages > Connexions**.
2. **Étape 2 :** Appuyez sur **Gestionnaire SIM**.
3. **Étape 3 :** Sélectionnez **Ajouter une eSIM**.
4. **Étape 4 :** Appuyez sur **Scanner le code QR du fournisseur de services**.
5. **Étape 5 :** Scannez le code et appuyez sur **Ajouter** lorsque vous y êtes invité.

### Pour les appareils Google Pixel :

1. **Étape 1 :** Allez dans **Réglages > Réseau & Internet**.
2. **Étape 2 :** Appuyez sur le **+ (icône plus)** à côté de **SIM**.
3. **Étape 3 :** Appuyez sur **Télécharger une SIM à la place ?** en bas.
4. **Étape 4 :** Appuyez sur **Suivant** et scannez votre code QR.

## Activation via une application opérateur (la méthode alternative)

De nombreux fournisseurs d'eSIM de voyage (comme Airalo ou Holafly) et les grands opérateurs nationaux proposent une activation intégrée à l'application. Cela contourne complètement le code QR.

1. Téléchargez l'application officielle de votre fournisseur.
2. Connectez-vous à votre compte et localisez votre forfait acheté.
3. Appuyez sur le bouton **Activer** ou **Installer l'eSIM**.
4. Votre téléphone vous demandera l'autorisation de permettre à l'application d'installer un forfait cellulaire. Appuyez sur **Autoriser** ou **Continuer**.

## Comment confirmer que votre eSIM est activée avec succès

Une fois que vous avez effectué les étapes ci-dessus, voici comment vérifier que votre nouvelle eSIM est prête à être utilisée :

* **Vérifiez la barre d'état :** Regardez le coin supérieur droit de votre écran. Si vous avez à la fois votre SIM physique et votre eSIM activées, vous devriez voir deux séries distinctes de barres de signal cellulaire.
* **Vérifiez le menu Réglages :** Allez dans vos paramètres Cellulaires/Réseau. Vous devriez voir les deux lignes listées, et le statut de votre eSIM nouvellement ajoutée devrait indiquer **« Activé »** ou **« Actif »**.
* **Le test réel :** Désactivez votre Wi-Fi, basculez votre donnée cellulaire principale vers la nouvelle ligne eSIM et essayez de charger une page Web ou d'ouvrir une application. Si la connexion est fluide, votre activation est réussie à 100 % !

## Comment basculer entre plusieurs forfaits eSIM

Si vous êtes un voyageur fréquent, vous pouvez stocker plusieurs eSIM sur votre téléphone et basculer entre elles sans effort.

* **Sur iPhone :** Allez dans **Réglages > Données cellulaires > Données cellulaires**, et appuyez simplement sur le forfait que vous souhaitez utiliser pour l'accès Internet. *(Raccourci : Balayez vers le bas pour ouvrir le Centre de contrôle, appuyez longuement sur l'icône des données cellulaires et basculez rapidement votre ligne de données active).*
* **Sur Android :** Allez dans **Réglages > Réseau & internet > SIM**. Appuyez sur le forfait que vous souhaitez utiliser et activez l'option **« Utiliser la SIM »** ou **« Données mobiles »**.

> 💡 **Conseil de voyageur :** Vous pouvez installer votre eSIM de voyage à la maison. Une fois que votre avion atterrit à destination, il vous suffit d'aller dans vos réglages et de basculer vos Données cellulaires vers l'eSIM locale pour vous connecter instantanément.

## Dépannage des échecs d'activation courants

Si votre eSIM ne s'active pas ou ne se connecte pas, ne paniquez pas. Essayez ces correctifs techniques avant de contacter le support client.

### Erreur 1 : « Le forfait cellulaire ne peut pas être ajouté »
* **Solution :** Cela signifie généralement que votre téléphone est verrouillé par un opérateur, ou que le code QR a déjà été scanné. Les codes QR sont strictement à usage unique. Si votre téléphone est débloqué et que vous obtenez cette erreur, vous devez contacter votre fournisseur pour générer un nouveau code QR.

### Erreur 2 : « Code QR invalide » ou le code ne scanne pas
* **Solution :** Le code QR peut être expiré, endommagé, ou votre appareil photo ne peut pas faire le point. Assurez-vous de scanner dans un endroit bien éclairé et que l'écran affichant le code est lumineux. Si cela échoue encore, appuyez sur « Entrer les détails manuellement » et saisissez l'**adresse SM‑DP+** et le **code d'activation** fournis par votre opérateur.

### Problème 1 : L'eSIM est installée mais affiche « Aucun service »
* **Solution :** Le profil a été téléchargé, mais votre téléphone ne s'est pas enregistré auprès de la tour de téléphonie locale. Tout d'abord, assurez-vous que la ligne eSIM est activée **ON** dans vos réglages. Ensuite, activez le **mode Avion** pendant 30 secondes, puis désactivez-le. Cela force l'antenne de votre téléphone à redémarrer et à rechercher un signal.

### Problème 2 : Activée avec succès, mais pas de connexion Internet
* **Solution :** Si vous avez des barres de signal mais que les pages ne se chargent pas, vérifiez deux choses :
  1. **Activez l'itinérance des données :** Allez dans vos paramètres eSIM et assurez-vous que la bascule « Itinérance des données » est activée (c'est obligatoire pour la plupart des eSIM de voyage).
  2. **Vérifiez les paramètres APN :** Trouvez le menu **APN (Nom du point d'accès)** dans vos paramètres cellulaires. Demandez à votre fournisseur les détails APN corrects et saisissez-les manuellement. *(Cette étape est particulièrement courante pour les appareils Android).*
  3. **Vérifiez la ligne de données :** Assurez-vous que la « Donnée cellulaire » principale de votre téléphone est bien attribuée à la nouvelle eSIM, et non à votre SIM domestique.

> **AVERTISSEMENT CRITIQUE :** Ne touchez jamais à **Supprimer l'eSIM** ou **Supprimer le forfait de données** si vous essayez de résoudre un problème de connexion. La suppression de l'eSIM détruit définitivement le profil numérique, et vous devrez en acheter un nouveau.

## Questions fréquentes

**Y a-t-il des frais pour activer une eSIM ?** Non, les opérateurs ne facturent pas de « frais d'activation » juste pour scanner et installer un profil eSIM. Vous ne payez que pour le forfait de données ou le forfait cellulaire que vous avez acheté.

**Puis-je activer mon eSIM avant de voyager ?** Oui, et c'est fortement recommandé. Vous devriez installer l'eSIM à la maison pendant que vous avez une connexion Wi-Fi fiable. Le forfait de données restera simplement inactif (ou « en recherche ») jusqu'à ce que vous atterrissiez dans votre pays de destination et que votre téléphone se connecte au réseau local pris en charge.

**Comment basculer entre ma SIM physique et mon eSIM ?** Allez dans vos paramètres cellulaires. Vous verrez les deux lignes listées. Vous pouvez appuyer sur votre SIM physique pour la désactiver, ou définir votre SIM physique comme ligne par défaut pour la Voix/SMS, et l'eSIM comme ligne par défaut pour les Données cellulaires.
