## 빠른 답변: iPhone XR eSIM 지원 설명

**예 – iPhone XR은 eSIM을 완벽히 지원합니다.** 2018년에 출시되었으며, XS 및 XS Max와 함께 eSIM 기술을 탑재한 최초의 iPhone 중 하나였습니다.

2026년 현재 10초 만에 알아야 할 사항:

1. **지역 확인:** 모든 글로벌 모델이 작동합니다. 중국 본토 버전은 eSIM이 없습니다. 홍콩/마카오 모델은 부분 지원합니다 (물리적 SIM 1개 + eSIM 1개).
2. **`*#06#`으로 확인:** 이 번호를 다이얼하세요. 32자리 EID가 나타나면 기기가 준비된 것입니다.
3. **몇 분 안에 활성화:** 여행 전에 제공업체의 QR 코드를 스캔하세요. 도착 후 데이터 로밍을 켜세요.

**전문가 팁:** XR이 구형이지만, eSIM 기능은 최신 iPhone과 정확히 동일하게 작동합니다 – 속도나 기능 제한이 없습니다 (XR에는 어차피 5G가 없지만요). 다른 모델에 대한 자세한 내용은 **[전체 호환성 가이드](/compatibility/)**를 참조하세요.


## iPhone XR eSIM 호환 – 한눈에 보기

| 기능 | 상태 |
| :--- | :--- |
| **eSIM 지원** | ✅ 예 (글로벌 모델) |
| **듀얼 SIM (물리적 nano-SIM + eSIM)** | ✅ 예 |
| **저장 가능 프로필 수** | 최대 8개 이상 (한 번에 하나만 활성) |
| **활성 회선 수** | 물리적 SIM 1개 + eSIM 1개 (듀얼 스탠바이) |
| **eSIM에서 5G 지원** | ❌ 아니요 – iPhone XR은 4G LTE 전용 |
| **중국 본토 버전** | ❌ eSIM 없음 – 듀얼 물리적 SIM 전용 |
| **홍콩 / 마카오 버전** | ⚠️ 제한적 – `*#06#`으로 확인 |

XR은 **iOS 12.1 이상**에서 eSIM을 지원합니다. 몇 년 동안 소프트웨어를 업데이트하지 않았다면 **설정 > 일반 > 소프트웨어 업데이트**로 이동하세요. 최상의 경험을 위해 **iOS 16 이상**을 권장합니다.

### 하드웨어 배경 – 중국 모델에 eSIM이 없는 이유

이 기기에는 eSIM 기능을 활성화하는 **eUICC**(임베디드 범용 집적 회로 카드)라는 물리적 칩이 포함되어 있습니다. 그러나 Apple은 중국 본토에서 판매되는 iPhone에서 이 칩을 물리적으로 제거하거나 비활성화하여 듀얼 물리적 SIM 슬롯을 요구하는 현지 규정을 준수합니다.

**이는 소프트웨어 제한이 아닌 하드웨어 문제입니다.** 어떤 iOS 업데이트도 중국 모델 XR에 eSIM을 추가할 수 없습니다. 출처를 알 수 없는 중고 기기를 구매하는 경우, 구매 전 항상 EID를 확인하세요. 중국 정부는 중국 본토에서 판매되는 모든 휴대폰에 듀얼 물리적 SIM 슬롯을 요구하므로, Apple은 해당 모델에서 eSIM 하드웨어를 제거합니다.

**이렇게 생각해보세요:** 선루프가 없는 자동차를 구입하는 것과 같습니다. 소프트웨어 업데이트로 선루프를 추가할 수 없습니다 – 포함되어 있거나 없는 하드웨어 기능입니다. eSIM도 마찬가지입니다.


## iPhone XR이 eSIM을 지원하는지 확인하는 방법

세 가지 방법 – 첫 번째가 가장 신뢰할 수 있습니다.

### 방법 1: EID 코드 (가장 빠르고 신뢰할 수 있음)

1. 전화 앱(다이얼러)을 엽니다.
2. `*#06#`을 입력하고 통화 버튼을 누릅니다.
3. 화면을 확인합니다:
   - **EID(32자리)가 나타남** → 기기가 eSIM을 지원합니다. ✅
   - **IMEI 번호만 나타남** → eSIM 없음 (중국 모델일 가능성이 높음). ❌

**찾아야 할 것은?**
- **IMEI** (15자리) – 휴대폰 하드웨어를 식별합니다. 모든 휴대폰에 있습니다.
- **EID** (32자리) – eSIM 칩을 식별합니다. eSIM 지원 휴대폰에만 있습니다.

EID가 보이면 휴대폰에 해당 하드웨어가 있는 것입니다. 보이지 않으면 eSIM 사용이 물리적으로 불가능합니다.

### 방법 2: 설정에서 확인

**설정 > 일반 > 정보**로 이동합니다. "사용 가능한 SIM" 또는 "디지털 SIM" 섹션까지 스크롤합니다. EID가 나열되어 있으면 기기가 준비된 것입니다.

### 방법 3: 요금제 추가 시도

**설정 > 셀룰러 > 셀룰러 요금제 추가**로 이동합니다. 옵션이 회색으로 표시되거나 없으면 기기가 eSIM을 지원하지 않는 것입니다. 탭할 수 있으면 사용 가능합니다.


## eSIM 여행용 중고 iPhone XR 구매 시 체크리스트

eSIM 사용을 목적으로 중고 XR을 구매하는 경우, 직접 확인할 때 이 체크리스트를 사용하세요:

| 단계 | 확인 사항 |
| :--- | :--- |
| **1** | **설정 > 일반 > 정보 > 모델 번호** – **CH/A**로 끝나면 피하세요 (중국 모델). |
| **2** | **`*#06#` 다이얼** – **EID**가 나타나는지 확인하세요 (IMEI만 아님). |
| **3** | **설정 > 일반 > 정보 > 통신사 잠금** – **"SIM 제한 없음"**이라고 표시되어야 합니다. "SIM 잠김"이라고 표시되면 다른 통신사의 eSIM을 사용할 수 없습니다. |
| **4** | **설정 > 셀룰러** – **"셀룰러 요금제 추가"**가 회색이 아닌 탭 가능한지 확인하세요. |
| **5** | **원본 영수증 요청** – 도난품이 아니거나 계약이 남아 있지 않은지 확인하는 데 도움이 됩니다. |
| **6** | **무료 체험판으로 테스트** – 판매자가 허용한다면 무료 eSIM(Roami 등)을 설치하여 활성화가 작동하는지 확인하세요. |

### 중고 구매 시 주의 사항 (레드 플래그)

| 주의 사항 | 이유 |
| :--- | :--- |
| **`*#06#`에 EID 없음** | 중국 모델 – eSIM 하드웨어 없음. |
| **통신사 잠금이 "SIM 잠김"** | 여행용 eSIM을 사용할 수 없음. |
| **판매자가 "iOS만 업데이트하면 eSIM이 생긴다"고 함** | 거짓 – eSIM은 하드웨어이지 소프트웨어가 아님. |
| **물리적 SIM 트레이가 보이지 않음** | XR에는 SIM 트레이가 있음 – 없으면 XR이 아님. |
| **iCloud 잠김** | 사실상 벽돌 상태 – 구매하지 마세요. |

### iPhone XR 모델 번호 – 빠른 참조

| 모델 번호 | 지역 | eSIM 지원 |
| :--- | :--- | :--- |
| **A2105** | 글로벌 (미국, 캐나다, 일본 등) | ✅ 예 |
| **A2106** | 글로벌 | ✅ 예 |
| **A2107** | 글로벌 | ✅ 예 |
| **A2108** | 중국 본토 | ❌ eSIM 없음 |
| **A2109** | 일본 (통신사) | ⚠️ 통신사 잠금 가능성 있음 |

**모델 번호 찾는 방법:** 설정 > 일반 > 정보 > 모델 번호. 번호를 탭하면 "AXXXX"와 "MNXXXXX/A" 형식 사이를 전환할 수 있습니다.


## iPhone XR에서 eSIM 활성화 방법

활성화는 2분도 걸리지 않습니다. 비행 전에 하세요 – Wi-Fi만 있으면 됩니다. 모든 iPhone 모델에 대한 자세한 지침은 **[iPhone eSIM 활성화 가이드](/faq/how-to-activate-esim-on-iphone/)**를 확인하세요.

### 단계별 활성화

| 단계 | 작업 |
| :--- | :--- |
| **1** | eSIM 요금제 구매 – 여행용으로 아무 제공업체나 선택하세요. Roami에서 무료 체험판도 제공합니다. |
| **2** | **설정 > 셀룰러 > 셀룰러 요금제 추가**를 엽니다. |
| **3** | 이메일로 받은 QR 코드를 스캔합니다. (수동 활성화 코드가 있으면 "수동으로 세부 정보 입력"을 탭하세요.) |
| **4** | 요금제에 라벨을 지정하세요 – 예: "여행", "업무", "영국 데이터". |
| **5** | 기본 회선 선택 – 셀룰러 데이터, 음성, SMS에 사용할 회선을 결정합니다. |
| **6** | **중요 단계:** 목적지에 도착한 후 **설정 > 셀룰러 > [내 요금제]**로 이동하여 **데이터 로밍**을 켜세요. 이 작업을 하지 않으면 연결되지 않습니다. |

### APN 설정 (데이터 연결이 안 될 경우)

활성화 후 데이터 네트워크를 사용할 수 없는 경우 APN 설정을 조정해야 할 수 있습니다:

1. **설정 > 셀룰러 > 셀룰러 데이터 네트워크**로 이동합니다.

## 물리적 SIM과 eSIM 함께 사용하기

iPhone XR은 **듀얼 SIM 듀얼 스탠바이(DSDS)**를 지원합니다 – 물리적 SIM 1개와 eSIM 1개를 동시에 활성화할 수 있습니다.

### "듀얼 스탠바이"의 의미

| 기능 | 작동 방식 |
| :--- | :--- |
| **두 회선 모두 활성** | 휴대폰이 두 네트워크에 동시에 연결됨 |
| **통화 중** | 다른 회선에 "서비스 없음"이 표시됨 – 이는 **정상**입니다 (듀얼 액티브가 아닌 듀얼 스탠바이) |
| **데이터** | 셀룰러 데이터를 제공할 회선을 선택 |
| **통화/SMS** | 기본 음성 회선을 선택 |

### 여행 시 권장 설정

| 설정 | 권장값 | 이유 |
| :--- | :--- | :--- |
| **기본 음성 회선** | 집 물리적 SIM | 집 전화번호로 계속 수신 |
| **셀룰러 데이터** | 여행용 eSIM | 비싼 로밍 대신 현지 데이터 요금제 사용 |
| **데이터 로밍 (집 SIM)** | 끄기 | 우발적 로밍 요금 방지 |
| **데이터 로밍 (여행용 eSIM)** | 켜기 | 여행용 eSIM 작동에 필수 |

### iPhone XR에 저장할 수 있는 eSIM 프로필은 몇 개인가요?

XR은 **최대 8개**의 eSIM 프로필을 저장할 수 있지만, 물리적 SIM과 함께 **한 번에 하나의 eSIM만 활성화**할 수 있습니다.

**사용하지 않는 프로필 삭제 방법:**
1. 설정 > 셀룰러 > 삭제할 요금제를 탭합니다.
2. 아래로 스크롤하여 **셀룰러 요금제 제거**를 탭합니다.
3. 새 프로필을 위한 저장 공간이 확보됩니다.

**저장된 프로필 간 전환 방법:**
1. 설정 > 셀룰러 > 원하는 요금제를 탭합니다.
2. **이 회선 켜기**를 전환합니다.

## iPhone XR eSIM 문제 해결

| 문제 | 가능한 원인 | 해결책 |
| :--- | :--- | :--- |
| **"셀룰러 요금제를 추가할 수 없음"** | 저장된 프로필이 너무 많음 | 사용하지 않는 프로필 삭제 (설정 > 셀룰러 > 셀룰러 요금제 제거) |
| **설치했지만 데이터 없음** | 데이터 로밍이 꺼져 있음 | 해당 회선의 데이터 로밍 켜기 |
| **"eSIM이 지원되지 않습니다"** | iOS 구버전 또는 호환되지 않는 프로필 | iOS 16+로 업데이트, 제공업체에 문의 |
| **활성화 후 "SIM 없음"** | 프로필 손상 | 삭제 후 재설치 |
| **QR 코드 "유효하지 않음"** | QR 만료 또는 이미 사용됨 | 제공업체에 새 QR 요청 |
| **오랫동안 "검색 중" 표시** | 범위 밖 | 수동 네트워크 선택 시도 (설정 > 셀룰러 > [요금제] > 네트워크 선택) |
| **eSIM 회선에서 통화가 음성 사서함으로 감** | 기본 음성 회선이 잘못 설정됨 | 설정 > 셀룰러 > 기본 음성 회선 – 올바른 회선 선택 |
| **통화 중 다른 회선에 서비스 없음 표시** | 정상적인 듀얼 스탠바이 동작 | 수정할 사항 없음 – 이게 정상 작동 방식입니다. |

더 고급 문제 해결은 **[eSIM 심층 문제 해결 가이드 2026](/faq/esim-deep-troubleshooting-guide-2026/)**를 참조하세요.


## 자주 묻는 질문

**iPhone XR이 모든 통신사와 eSIM 호환이 되나요?**
예 – eSIM을 제공하는 모든 통신사(후불, 선불 또는 여행용 eSIM)가 기기가 잠금 해제된 경우 작동합니다.

**eSIM과 물리적 SIM을 동시에 사용할 수 있나요?**
예. 활성 eSIM 1개 + 활성 물리적 SIM 1개를 동시에 가질 수 있습니다 – 이는 진정한 듀얼 SIM 듀얼 스탠바이 설정입니다.

**iPhone XR이 5G eSIM을 지원하나요?**
아니요 – iPhone XR은 4G LTE만 지원합니다. eSIM은 LTE에서 완벽하게 작동하지만 5G 속도를 얻을 수는 없습니다.

**기기에 "셀룰러 요금제를 추가할 수 없음"이 표시됩니다 – 무엇이 문제인가요?**
저장된 프로필이 너무 많을 때 자주 발생합니다. 설정 > 셀룰러로 이동하여 오래되었거나 사용하지 않는 프로필을 제거하세요. 그런 다음 재시작하고 다시 시도하세요. XR은 약 8개의 프로필을 저장할 수 있습니다.

**iPhone XR eSIM이 유럽에서 작동하나요?**
예 – 하지만 영국 기반 현지 eSIM은 브렉시트 이후 일일 EU 로밍 수수료를 부과한다는 점을 알아두세요. 여러 국가를 여행하는 경우 지역 유럽 eSIM을 대신 구매하세요.

**iPhone X (iPhone 10)이 eSIM을 지원하나요?**
아니요. iPhone X(2017년 출시)에는 eSIM 하드웨어가 없습니다. eSIM이 탑재된 최초의 iPhone은 XR, XS 및 XS Max입니다.

**iPhone 8 또는 8 Plus가 eSIM을 지원하나요?**
아니요. iPhone 8 및 8 Plus는 물리적 SIM 전용입니다. eSIM을 지원하지 않습니다.

**iPhone XR에 저장할 수 있는 eSIM 프로필은 몇 개인가요?**
최대 8개의 프로필을 저장할 수 있지만 물리적 SIM과 함께 한 번에 하나만 활성화할 수 있습니다.

**iPhone XR에서 두 개의 eSIM을 동시에 사용할 수 있나요?**
아니요 – XR은 한 번에 하나의 활성 eSIM만 지원합니다 (물리적 SIM 1개 추가). 듀얼 eSIM(두 개의 활성 eSIM)은 iPhone 13부터 시작되었습니다.

**가장 저렴한 eSIM 지원 iPhone은 무엇인가요?**
iPhone XR(중고)은 약 $100–150에 가장 저렴한 eSIM 지원 iPhone입니다. iPhone SE (3세대)는 가장 저렴한 새 eSIM iPhone입니다.

**iPhone XR이 통신사 잠금 상태인지 어떻게 확인하나요?**
설정 > 일반 > 정보 > 통신사 잠금. "SIM 제한 없음"이라고 표시되면 iPhone이 잠금 해제된 것입니다. "SIM 잠김"이라고 표시되면 통신사에 연락하여 잠금 해제를 요청하세요.

**iPhone XR에서 T‑Mobile eSIM을 사용할 수 있나요?**
예. T‑Mobile은 XR에서 eSIM을 지원합니다. T‑Mobile 앱 또는 T‑Mobile의 QR 코드를 통해 활성화할 수 있습니다.

**iPhone XR에서 Verizon eSIM을 사용할 수 있나요?**
예. Verizon은 XR에서 eSIM을 지원합니다. My Verizon 앱 또는 Verizon의 QR 코드를 통해 활성화하세요.

**iPhone XR 여행에 가장 좋은 eSIM은 무엇인가요?**
가장 좋은 옵션은 목적지에 따라 다릅니다. 미국 여행의 경우 Roami(멀티 네트워크) 또는 Airalo(단일 네트워크) 모두 작동합니다. 유럽의 경우 Roami Europe 또는 Airalo Europe이 좋은 옵션입니다. 최상의 커버리지를 원한다면 멀티 네트워크 요금제를 찾아보세요.

**iPhone XR에 물리적 SIM 트레이가 있나요?**
예 – 미국 iPhone 14 및 이후 모델과 달리 XR에는 eSIM 지원과 함께 물리적 nano-SIM 트레이가 있습니다.

**iPhone XR에서 물리적 SIM을 eSIM으로 전환할 수 있나요?**
예 – iOS 16+에서 설정 > 셀룰러 > 셀룰러 요금제 추가 > "물리적 SIM에서 전환"으로 이동하세요. 이렇게 하면 동일한 기기에서 물리적 SIM이 eSIM으로 전환됩니다.

**통화 중 다른 회선에 "서비스 없음"이 표시되는 이유는 무엇인가요?**
이는 정상적인 동작입니다. XR은 듀얼 액티브가 아닌 듀얼 스탠바이입니다 – 한 번에 하나의 회선만 셀룰러 연결을 유지할 수 있습니다. 통화가 끝나면 두 회선 모두 자동으로 다시 연결됩니다.

**다른 휴대폰 브랜드는 어떤가요? 내 Samsung / Xiaomi / Huawei가 eSIM 호환인가요?**
Samsung Galaxy S20 FE, Xiaomi 11T Pro 및 Huawei P30 Pro는 지역 및 모델에 따라 eSIM을 지원합니다. 전체 목록은 전체 **[eSIM 호환성 가이드](/compatibility/)**를 참조하세요.
