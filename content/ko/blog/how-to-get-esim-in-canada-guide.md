## 빠른 답변: 캐나다에서 eSIM을 받는 방법

캐나다 eSIM을 받는 데는 다섯 단계가 있습니다:

1. **호환성 확인** — `*#06#`을 눌러 EID를 확인하세요. 휴대폰이 통신사 잠금 해제되었는지 확인하세요.
2. **요금제 구매** — 여행 기간에 따라 데이터를 선택하세요. 출발 전 집 Wi-Fi에서 설치하세요.
3. **eSIM 설치** — QR 코드를 스캔하거나 수동 활성화 코드를 입력하세요.
4. **캐나다에서 활성화** — 데이터 로밍을 켜고, eSIM을 기본 데이터 회선으로 설정하세요.
5. **테스트 및 문제 해결** — 실패하면 먼저 수동 네트워크 선택을 사용하세요.

**필요 시간:** 15분. **설치 장소:** 집에서, 출발 전. **활성화 시점:** 캐나다 네트워크에 연결될 때 자동으로.

**결정하기 전에 테스트하고 싶으신가요?** [무료 eSIM 체험](/free-esim/)을 사용하거나 [Roami 캐나다 eSIM 요금제](/canada-esim/)를 **$1.99**부터 시작하여 여행 전에 설정과 커버리지를 테스트해 보세요. 신규 사용자는 코드 `web20`으로 **20% 할인**을 받을 수 있으며, 설정이 막히면 Roami의 **24/7 사람 지원**이 준비되어 있습니다.

## 캐나다 eSIM 호환성 및 준비

캐나다 eSIM 요금제를 구매하기 전에 휴대폰이 eSIM을 지원하고 통신사 잠금 해제되었는지 확인하세요. 이 섹션은 가장 빠른 확인 방법, 주요 브랜드의 설정 경로, 나중에 대부분의 설치 문제를 방지하는 준비 단계를 보여줍니다.

### 캐나다 eSIM 호환성: 30초 EID 확인

요금제를 구매하기 전에 휴대폰이 eSIM을 지원하는지 확인하세요. 가장 빠른 방법은 iPhone과 Android 모두에서 작동합니다:

1. **다이얼러**를 여세요.
2. **`*#06#`**을 입력하세요.
3. **EID** (eSIM 식별자), 32자리 코드를 찾으세요.

**EID가 보이면:** 휴대폰에 eSIM 하드웨어가 있습니다.  
**IMEI만 보이면:** 휴대폰이 eSIM을 지원하지 않습니다.

**확인할 사항:** iPhone에서 EID는 IMEI 아래에 나타납니다. Samsung에서는 "EID" 또는 "eSIM ID"로 나타날 수 있습니다. 두 개의 IMEI 번호 (IMEI1 및 IMEI2)만 보이면 휴대폰에 eSIM 하드웨어가 없습니다.

브랜드 및 지역별 전체 기기 목록은 [휴대폰 호환성 가이드](/blog/esim-compatible-phones-canada-guide/)를 참고하세요.

eSIM은 [GSMA](https://www.gsma.com/esim/)가 정의한 표준이며, 32자리 EID는 기기가 eSIM 프로필을 등록하는 데 사용하는 식별자입니다.

### 브랜드별 빠른 eSIM 설정 확인

다이얼하지 않으려면 설정 앱을 사용하세요:

- **iPhone:** 설정 → 일반 → 정보 → "사용 가능한 SIM" 또는 "통신사 잠금"을 찾으세요.
- **Samsung:** 설정 → 연결 → SIM 관리자 → "eSIM 추가"를 찾으세요.
- **Google Pixel:** 설정 → 네트워크 및 인터넷 → SIM → "대신 SIM을 다운로드하시겠습니까?"를 찾으세요.
- **기타 Android 브랜드:** 설정에서 "eSIM"을 검색하세요.

옵션이 보이면 휴대폰이 eSIM을 지원합니다. 그렇지 않으면 [기기 호환성 데이터베이스](/blog/esim-compatible-phones-canada-guide/)의 지역별 참고 사항을 확인하세요.

**중요:** 중국 본토와 홍콩에서 판매되는 iPhone은 eSIM을 지원하지 않습니다. 중국 본토의 유일한 예외는 iPhone 17e와 iPhone Air입니다. 자세한 내용은 [기기 가이드](/blog/esim-compatible-phones-canada-guide/)를 참고하세요.

### 캐나다 eSIM 통신사 잠금 해제 확인

휴대폰이 eSIM을 지원하더라도 통신사 잠금이 해제되어 있어야 합니다.

- **iPhone:** 설정 → 일반 → 정보 → **통신사 잠금**이 "SIM 제한 없음"으로 표시되어야 합니다.
- **Android:** 설정 → 휴대폰 정보 → 상태 → 네트워크/SIM 상태를 확인하세요.

캐나다에서 CRTC는 Bell, Rogers, Telus, Freedom Mobile이 기기를 무료로 잠금 해제하도록 요구합니다. [CRTC 무선 코드](https://crtc.gc.ca/eng/phone/mobile/codes.htm)를 참고하세요.

**전문가 팁:** 캐나다 통신사에서 중고 Samsung을 구매했다면 eSIM이 기본적으로 비활성화되어 있을 수 있습니다. 구매 전에 통신사에 확인하세요. 통신사 잠금 해제 단계는 [기기 가이드](/blog/esim-compatible-phones-canada-guide/)를 참고하세요.

### eSIM 설정 준비

eSIM 설치에는 인터넷 연결이 필요합니다. **출발 전 집에서 하세요.** 공항 Wi-Fi는 종종 느리고 불안정합니다. 착륙할 때까지 기다리면 설치에 어려움을 겪을 수 있습니다.

시작하기 전에 확인하세요:

- **Wi-Fi:** 안정적인 집 Wi-Fi. 공용 Wi-Fi를 사용하지 마세요.
- **전원:** 휴대폰 배터리 50% 이상, 또는 충전 중.
- **저장 공간:** 최소 1GB 여유 공간.
- **QR 코드:** 저장되어 있고 접근 가능.
- **수동 활성화 코드:** 백업으로 저장.

**일반적인 사용자 보고:** 여행자들이 토론토 피어슨에 착륙하여 공항 Wi-Fi에서 eSIM을 설치하려다 Wi-Fi가 인증을 위해 캐나다 전화번호를 요구한다는 것을 발견했다고 보고했습니다. 일부는 카페에서 열린 네트워크를 찾기 전까지 공항에서 40분을 보냈습니다.

### eSIM 설정 전에 필요한 것

- 휴대폰 (호환 및 잠금 해제)
- 안정적인 Wi-Fi 연결
- 결제 수단 (신용카드, PayPal, Apple Pay, Google Pay)
- 제공업체의 QR 코드 또는 수동 활성화 코드
- 10–15분의 시간

### eSIM 설치 vs 활성화

여기서 대부분의 첫 사용자가 혼란스러워합니다.

**설치:** eSIM 프로필을 휴대폰에 다운로드합니다. Wi-Fi가 필요합니다. 출발 전에 할 수 있습니다. eSIM이 셀룰러 목록에 나타나지만 **연결되지 않고, 데이터를 사용하지 않으며, 유효 기간 시계가 시작되지 않습니다**.

**활성화:** eSIM이 캐나다 네트워크에 처음 연결될 때 자동으로 트리거됩니다. 유효 기간이 시작되고 데이터 사용량이 계산되기 시작합니다.

**의미:** 유효 기간을 낭비하지 않고 1~2주 일찍 설치할 수 있습니다. 대부분의 여행 eSIM은 첫 네트워크 연결 시 활성화됩니다. 일부 제공업체는 도착 후에만 설치를 요구합니다—**구매 전에 활성화 정책을 읽으세요**.

**일반적인 사용자 보고:** 한 여행자가 밴쿠버로 비행하기 2주 전에 런던에서 eSIM을 설치했습니다. 요금제는 활성화로부터 30일 유효했습니다. 착륙하여 데이터 로밍을 켰고, 30일 시계는 휴대폰이 Bell에 연결될 때만 시작되었습니다. 14일의 유효 기간을 절약했습니다.

제공업체별 활성화 정책은 [비교 데이터베이스](/blog/canada-esim-comparison-2026/)를 참고하세요.

- 로드트립에 너무 적은 데이터 구매.

**결정 체크리스트:**
1. 캐나다 전화번호가 필요한가요? 그렇다면 [번호 포함 캐나다 eSIM 옵션](/blog/canada-esim-with-phone-number-guide/)을 참고하세요.
2. 미국으로 건너가나요? 그렇다면 [국경 간 eSIM 가이드](/blog/usa-and-canada-esim-guide/)를 참고하세요.
3. 밴프, 재스퍼, 로키 산맥을 방문하나요? 그렇다면 Bell/Telus를 선택하세요. [네트워크 커버리지 가이드](/blog/canada-esim-coverage-guide/)를 참고하세요.
4. 여행 기간은 얼마나 되나요? 데이터를 여행 기간에 맞추세요 (위의 데이터 계획 표 참고).

## iPhone에 eSIM 설치: 단계별

iPhone eSIM 설정 과정은 iOS 16 이상에서 유사합니다. 아래 단계는 여행 eSIM 추가를 위한 표준 Apple 메뉴 경로와 일치합니다.

### 표준 eSIM QR 설치 (iOS 16+)

1. **설정**을 여세요.
2. **셀룰러** (또는 모바일 데이터)를 탭하세요.
3. **eSIM 추가**를 탭하세요.
4. **QR 코드 사용**을 선택하세요.
5. 제공업체 이메일의 QR 코드를 스캔하세요.
6. eSIM 이름을 지정하세요 (예: "캐나다 여행").
7. 설치를 확인하세요.

**보게 될 것:** 스캔 후 iPhone이 eSIM 프로필을 다운로드합니다. 10–30초 걸립니다. "eSIM 추가됨" 또는 유사한 메시지가 표시됩니다.

**화면 표시:** "eSIM 추가" 화면에 옵션이 표시됩니다: "QR 코드 사용", "근처 iPhone에서 전송", "수동으로 세부 정보 입력". "QR 코드 사용"을 선택하세요. 스캔 후 iOS는 진행 스피너를 표시한 다음 "eSIM 추가됨"을 표시합니다.

### 자동 eSIM 설치 (일부 통신사)

설정에 **"통신사 셀룰러 요금제 설치 준비됨"**이 보이면 탭하고 안내를 따르세요. 일부 iPhone 17 이상 모델과 일부 통신사 eSIM에 적용됩니다.

**중요:** 이것은 여행 eSIM 설치와 같지 않습니다. 여행 eSIM은 거의 항상 QR 코드 또는 수동 활성화를 사용합니다.

### 수동 eSIM 활성화 코드

1. 설정 → 셀룰러 → eSIM 추가.
2. **수동으로 세부 정보 입력**을 선택하세요.
3. 이메일의 SM-DP+ 주소와 활성화 코드를 입력하세요.
4. 안내를 따르세요.

**보게 될 것:** iOS가 "SM-DP+ 주소"와 "활성화 코드"를 요청합니다. 제공업체 이메일에 있습니다. 주의 깊게 복사하여 붙여넣으세요.

### 설치 후 eSIM 확인

- 설정 → 셀룰러 → 새 eSIM이 나타나는지 확인.
- **"이 회선 켜기"**가 활성화되어 있는지 확인.
- **아직 데이터 로밍을 켜지 마세요**—캐나다에 도착할 때까지 기다리세요.

**화면 표시:** eSIM이 "셀룰러 요금제" 아래에 지정한 이름으로 나타납니다. "이 회선 켜기"가 켜져 있습니다. "데이터 로밍"이 꺼져 있습니다.

### eSIM을 위한 iOS 버전 차이

| iOS 버전 | 경로 | 비고 |
|-------------|------|-------|
| iOS 16 | 설정 → 셀룰러 → eSIM 추가 | 표준 |
| iOS 17 | 설정 → 셀룰러 → eSIM 추가 | 동일 |
| iOS 18 | 설정 → 셀룰러 → eSIM 추가 | 동일하지만 정보의 "사용 가능한 SIM"이 더 자세히 표시 |
| iOS 19 (미래) | 설정 → 셀룰러 → eSIM 추가 | Apple 문서 확인 |

**전문가 팁:** "eSIM 추가"를 찾을 수 없으면 설정에서 "eSIM"을 검색하세요. iOS 검색이 찾아줍니다.

### eSIM 전용 iPhone 14 이상 (미국)

미국 버전 iPhone 14, 15, 16, 17은 eSIM 전용일 수 있습니다 (물리적 SIM 트레이 없음). 미국 iPhone이 있으면 물리적 캐나다 SIM을 사용할 수 없습니다. eSIM을 사용해야 합니다. 이 가이드는 여전히 적용됩니다. 캐나다 iPhone 모델은 대부분 물리적 SIM 트레이를 유지하므로 물리적 SIM과 eSIM을 모두 사용할 수 있습니다. [기기 호환성 가이드](/blog/esim-compatible-phones-canada-guide/)에서 모델을 확인하세요.

## Android에 eSIM 설치: 단계별

Android eSIM 설치는 브랜드에 따라 다르지만 핵심 단계는 유사합니다. Samsung, Google 및 기타 제조업체는 약간 다른 메뉴 이름을 사용하므로 아래 경로를 가이드로 사용하세요.

2. **eSIM 추가**를 탭하세요.
3. **QR 코드 스캔**을 선택하세요.
4. QR 코드를 스캔하세요.
5. 다운로드 및 활성화 안내를 따르세요.

**보게 될 것:** Samsung이 "SIM 다운로드 중"을 표시한 다음 "SIM 추가됨"을 표시합니다. eSIM이 SIM 관리자에 나타납니다.

**화면 표시:** One UI 6에서 "eSIM 추가"는 SIM 관리자 하단에 있습니다. 스캔 후 진행 표시줄이 나타나고 "SIM 추가됨"이 표시됩니다.

### Google Pixel에 eSIM 설치

3. QR 코드를 스캔하거나 활성화 코드를 수동으로 입력하세요.
4. 안내를 따르세요.

**보게 될 것:** Pixel이 "SIM 다운로드 중"을 표시한 다음 "SIM 추가됨"을 표시합니다. eSIM이 SIM 아래에 나타납니다.

### 기타 Android 브랜드에 eSIM 설치

- **eSIM 추가** 또는 **SIM 다운로드**를 선택하세요.
- QR을 스캔하거나 활성화 코드를 입력하세요.

**팁:** 경로를 찾을 수 없으면 설정에서 "eSIM"을 검색하세요.

**브랜드별 참고:**

- **Xiaomi:** 설정 → 연결 및 공유 → SIM 카드 → eSIM 추가.

## 캐나다에서 eSIM 활성화

활성화는 eSIM이 캐나다 네트워크에 처음 연결될 때 시작됩니다. 대부분의 경우 착륙하여 데이터 로밍을 활성화한 후 자동으로 발생합니다. 핵심은 듀얼 SIM 옵션을 올바르게 설정하여 홈 SIM에서 비싼 로밍 요금이 발생하지 않도록 하는 것입니다.

### 착륙 후 캐나다 eSIM 활성화

1. **데이터 로밍 켜기**
   - iPhone: 설정 → 셀룰러 → eSIM 탭 → 데이터 로밍 켜기.
   - Android: 설정 → 네트워크 및 인터넷 → eSIM 탭 → 데이터 로밍 켜기.

2. **기본 데이터 회선 설정**
   - iPhone: 설정 → 셀룰러 → 셀룰러 데이터 → 캐나다 eSIM 선택.
   - Android: 설정 → 네트워크 및 인터넷 → SIM → 캐나다 eSIM 선택.

3. **음성용 원래 번호 유지**
   - iPhone: 설정 → 셀룰러 → 기본 음성 회선 → 원래 번호 선택.
   - Android: 설정 → 네트워크 및 인터넷 → SIM → 음성 회선 설정.

4. **연결 테스트**
   - 브라우저 또는 지도 앱을 여세요.

**활성화 타이밍:** 캐나다 파트너 네트워크에 연결 후 보통 1–5분. 5분 후에도 데이터가 없으면 문제 해결 섹션을 참고하세요.

**화면 표시:** 데이터 로밍을 켠 후 상태 표시줄에 통신사 이름이 나타납니다 (Bell, Rogers, Telus). eSIM 회선에 "데이터 로밍: 켜짐"이 표시됩니다.

### 권장 eSIM 듀얼 SIM 설정

| 설정 | 권장 | 이유 |
|---------|-------------|-----|
| 기본 데이터 회선 | 캐나다 eSIM | 로밍 요금 방지 |
| 기본 음성 회선 | 원래 번호 | 은행 코드와 통화 수신 |
| 원래 번호의 데이터 로밍 | 끄기 | 우발적 요금 방지 |
| 셀룰러 데이터 전환 허용 | 끄기 | 원래 번호로 데이터 전환 방지 |

**중요:** "셀룰러 데이터 전환 허용"을 켜면 캐나다 eSIM 신호가 약할 때 휴대폰이 홈 SIM으로 전환될 수 있습니다. 이는 로밍 요금을 유발할 수 있습니다. 꺼두세요.

### eSIM으로 Wi-Fi 통화

홈 통신사가 Wi-Fi 통화를 지원하면 로밍 요금 없이 Wi-Fi로 원래 번호에서 통화할 수 있습니다. 설정 → 전화 → Wi-Fi 통화에서 활성화하세요. 안정적인 호텔이나 카페 Wi-Fi에서 가장 잘 작동합니다.

**주의:** Wi-Fi 통화 품질은 Wi-Fi에 따라 다릅니다. Wi-Fi가 약하면 통화가 끊길 수 있습니다. 중요한 통화에는 가능하면 캐나다 eSIM의 음성 회선을 사용하세요.

### 캐나다 eSIM 데이터 절약 팁

- Wi-Fi에서 오프라인 지도 다운로드 (Google Maps, Apple Maps).
- 자동 앱 업데이트 끄기.
- Wi-Fi에서 영상과 음악 캐시.
- 설정에서 앱별 데이터 사용량 확인.
- 백그라운드 앱 새로 고침 끄기.
- 화상 통화 대신 WhatsApp/iMessage 사용.
- 기사에는 브라우저 리더 모드 사용.
- 소셜 미디어에서 동영상 자동 재생 끄기.

**관광객 일일 데이터 예산:**
- 내비게이션: 100–200MB
- 소셜 미디어: 150–300MB
- 음악 스트리밍: 150–300MB
- 사진 업로드: 50–100MB
- 날씨/앱: 20–50MB
- **가벼운 날 총계:** ~500MB–1GB
- **헤비한 날 총계:** 1–2GB+

### 캐나다 eSIM 연결 테스트

활성화 후 다음 테스트를 실행하세요:

1. **웹사이트 열기** — 데이터가 작동하는지 확인.
2. **Google Maps 열기** — 내비게이션 데이터가 작동하는지 확인.
3. **WhatsApp 메시지 보내기** — 메시징이 작동하는지 확인.
4. **네트워크 통신사 확인** — 설정 → 셀룰러 → Bell/Rogers/Telus가 표시되어야 함.
5. **속도 테스트 실행** — Speedtest.net 또는 Fast.com 사용. 예상: 도시에서 20–150 Mbps, 시골에서 5–50 Mbps.

테스트가 실패하면 문제 해결로 진행하세요.

### 캐나다 eSIM이 연결되지 않음

1. **2–3분 기다리세요.** 휴대폰이 캐나다 네트워크에 등록하는 데 시간이 필요합니다.
2. **비행기 모드를 30초 동안 토글**하세요.
3. **수동으로 네트워크 선택:** 설정 → 셀룰러 → 네트워크 선택 → 자동 끄기 → Bell, Rogers, Telus 선택.
4. **휴대폰을 재시작하세요.**
5. **eSIM의 데이터 로밍이 켜져 있는지 확인하세요.**
6. **제공업체 앱에서 요금제 상태를 확인하세요.**
7. **여전히 작동하지 않으면 지원에 문의하세요.**

대부분의 연결 문제는 수동 네트워크 선택으로 해결됩니다.

## 캐나다 eSIM 문제 해결

대부분의 캐나다 eSIM 문제는 몇 가지 범주에 속합니다: 설치 오류, 신호 없음, 데이터 없음, APN 문제, 통신사 선택. 아래 해결 방법을 순서대로 진행하세요.

### 캐나다 eSIM QR 코드가 스캔되지 않음

- 대신 **수동 활성화 코드**를 사용하세요.
- QR이 만료되었는지 확인하세요.
- 화면 밝기를 높이거나 QR을 인쇄하세요.
- 제공업체 지원에 새 QR을 요청하세요.
- 다른 기기의 화면에서 스캔해 보세요.

**일반적인 오류:** "잘못된 QR 코드" — 보통 QR이 만료되었거나 잘못 스캔되었음을 의미합니다. 수동 활성화 코드는 항상 작동합니다.

### eSIM이 설치되었지만 신호 없음

**1단계:** eSIM이 활성화되어 있는지 확인.  
**2단계:** 데이터 로밍이 켜져 있는지 확인.  
**3단계:** 자동 네트워크 선택을 끄고 **Bell / Rogers / Telus**를 수동으로 선택.  
**4단계:** 비행기 모드를 30초 동안 토글.  
**5단계:** 휴대폰 재시작.  
**6단계:** 제공업체 앱에서 요금제 상태 확인—만료되었거나 소진되었을 수 있음.

**수동 네트워크 선택은 "신호는 있지만 데이터 없음"에 대한 가장 효과적인 단일 해결책입니다.** 대부분의 경우를 해결합니다.

**수동으로 네트워크를 선택하는 방법:**
- iPhone: 설정 → 셀룰러 → 네트워크 선택 → 자동 끄기 → Bell/Rogers/Telus 선택.
- Android: 설정 → 네트워크 및 인터넷 → SIM → 통신사 → 자동 끄기 → 네트워크 선택.

### eSIM 신호는 있지만 데이터 없음

- 제공업체 이메일에서 APN 설정을 확인하세요.
- 기본 데이터 회선이 캐나다 eSIM인지 확인하세요.
- VPN을 일시적으로 끄세요.
- 비행기 모드를 토글하세요.
- 휴대폰을 재시작하세요.
