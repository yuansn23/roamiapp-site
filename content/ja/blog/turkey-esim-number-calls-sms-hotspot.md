## IMSI vs MSISDN：なぜほとんどのeSIMはデータ専用なのか

ほとんどのトラベルeSIMがデータ専用なのは、確認済みの現地加入者に割り当てられるMSISDNではなく、卸売ローミング契約に紐づくIMSIを使っているからです。この違いを理解すれば、このページのすべての制限が説明できます。

### トルコeSIMが現地回線に接続する仕組み

あなたのトラベルeSIMにはIMSIがあります。これは、プロバイダーとトルコのキャリアの卸売契約に紐づく固有の識別子です。スマホがTurkcell、Vodafone、Türk Telekomに接続すると、キャリアはIMSIを認証し、データセッションをルーティングします。

あなたは現地加入者ではないため、キャリアはMSISDNを割り当てません。+90 5XXで始まるトルコの電話番号は、確認済みの現地加入者に割り当てられます。ローミング中のIMSIに番号を割り当てるには、プロバイダーがあなたの代わりにパスポート登録を完了する必要があります。ほとんどのトラベルeSIMプロバイダーにはこれができません。

### GSMA仕様がトルコeSIMの音声について述べていること

[GSMA SGP.22 eSIM仕様](https://www.gsma.com/esim/)は、eSIMプロファイルのプロビジョニングと切り替えの方法を定義しています。音声やSMS対応は義務ではありません。これらはオプション機能です。だからこそ、同じeSIM技術でも、ある国ではフル機能のプランを、別の国ではデータ専用プランを提供できるのです。

## 本当にトルコの電話番号が必要なとき

ほとんどの観光用途では、トルコの+90番号は必要ありません。必要になるのは、トルコの銀行や政府サービスからSMSを受け取る必要がある、VoIPを受け付けないトルコの固定電話に発信する必要がある、発信者番号で選別する企業に電話する必要がある、トルコの番号を要求する現地サービスに登録する必要がある、SMSで認証するトルコのアプリを使う必要がある場合だけです。

### トルコの番号にできないこと

- 海外eSIMプラットフォームへのBTKブロックを回避できない。
- 120日のIMEI登録カウントを取り除けない。
- トルコ国内から海外eSIMプロバイダーのアプリへのアクセスを与えない。規制の全体像は[ブロックとIMEIルール](/blog/turkey-esim-ban-availability-rules/)をお読みください。

| ユースケース | トルコの番号が必要？ | 代替手段 |
|---|---|---|
| 銀行の2FA | 多くの場合はい | 自国SIMのローミングSMS |
| 政府サービス | はい | 現地SIM |
| レストラン予約 | 場合による | WhatsApp |
| 配車アプリ | 場合による | Uber、BiTaksi |
| フードデリバリー | 場合による | WhatsApp |
| ホテル連絡 | いいえ | WhatsApp、メール |
| 緊急サービス | いいえ | 112 |

## 仮想番号はトルコの2FAに実際に使えるのか？

SMS認証コードを受け取れる仮想番号を提供するアプリもあります。これらはあなたのトルコeSIMとは別物です。ほとんどのトルコの銀行は仮想番号に2FAコードを送らず、トルコの政府サービスは仮想番号を丸ごと拒否することが多いです。

### よく使われる仮想番号サービス

- Google Voice
- TextNow
- Burner
- Hushed

### 仮想番号が不足する場面

- ほとんどのトルコの銀行は仮想番号に2FAコードを送りません。
- トルコの政府サービスは仮想番号を拒否することが多いです。
- 仮想番号は本物の+90のモバイル番号ではありません。
- データ経由で動作するため、トルコeSIMの接続に依存します。

### トルコeSIMで2FAに実際に機能するもの

銀行とWhatsAppの2FAに確実な設定は：

1. 音声とSMS用に自国SIMを有効のまま保つ。
2. トルコeSIMをモバイルデータ回線に設定する。
3. 「モバイルデータ切り替えを許可」を無効にする。
4. 自国の番号がローミング経由でSMSを受け取る。

デュアルSIM設定の全体は、[デュアルSIM設定](/blog/how-turkey-esim-works-activation/)をお読みください。

## eSIMのデータで通話はできるか？

トルコで通話するのに、トルコの電話番号は必要ありません。必要なのはデータ接続と適切なアプリです。VoIPアプリが、トルコeSIMのデータ接続越しに音声通話とビデオ通話を処理します。

### トルコeSIMで使えるVoIPアプリ

- WhatsApp — 音声・ビデオ通話
- Telegram — 音声・ビデオ通話
- Skype — 音声・ビデオ通話、国際発信
- FaceTime — 音声・ビデオ通話
- Google Meet — ビデオ会議
- Zoom — ビデオ会議
- Microsoft Teams — 業務通話
- Signal — 暗号化通話

### トルコeSIMからの国際電話

トルコ国外への発信も、同じように分かれます。データ専用のトルコeSIMには電話番号がないため、従来型の国際電話はまったくできません — しかしデータ経由なら、WhatsAppやSkypeなどのアプリが、実際の電話番号への国際発信を処理します。アプリ間は無料、クレジットがあれば固定電話への分課金も安いことが多いです。本物の番号付き現地トルコSIMを持っていれば、従来型の国際電話も使えますが、トルコのキャリアレートで、安く設計されてはいません。ほとんどの旅行者にとっての実務パターン：着信は自国SIMを到達可能なまま保ち、発信の国際電話はeSIMのデータ越しにアプリで行う。それでも本物のトルコの番号が必要と判断したら、現地キャリアは観光用音声パックを市中のストアだけでなくオンラインでも販売しています — 支払う前に上の製品タイプと比較してください。

### トルコeSIMの通話品質の変動要因

| 要因 | 影響 |
|---|---|
| 信号強度 | 強い4G/5Gなら通話はクリア |
| FUP制限 | 1 Mbpsなら音声は可、ビデオは不調 |
| ネットワーク混雑 | 混雑時間帯は品質が劣化 |
| APNの設定ミス | データが流れないと通話は失敗 |

### VoIP vs ネイティブ通話

| 機能 | eSIM越しのVoIP | 現地SIM経由のネイティブ |
|---|---|---|
| トルコの固定電話に発信 | 可能（海外の発信者番号） | 可能 |
| トルコのモバイルに発信 | 可能（海外の発信者番号） | 可能 |
| 着信受信 | アプリ経由のみ | 可能（ネイティブ） |
| 緊急通報（112） | 可能（ダイヤラー経由） | 可能 |
| 通話品質 | データ速度次第 | 一貫している |
| コスト | 無料か安い | プランに含まれる |
| 現地番号の必要性 | 不要 | 必要 |

### トルコでVoIPはブロックされているか？

VoIPアプリはトルコで広く使われています。WhatsApp、Telegram、FaceTimeはデータ経由で機能します。一部の企業ネットワークやホテルはVoIPポートをブロックします。トルコのモバイル回線では、VoIPはBTKにブロックされていません。BTKブロックの対象はeSIMプロバイダーのプラットフォームであり、VoIPサービスではありません。

## Wi-Fi CallingはeSIM越しにどう機能するか？

自国キャリアがWi-Fi Calling（VoWiFi）に対応し、トルコでの利用を許していれば、トルコeSIMのデータ接続を使って、自国の番号で通話とSMSの送受信ができます。これは、データ専用のトルコeSIMで得られる、ネイティブ番号に最も近い体験です。

### Wi-Fi Callingがデータ越しにルーティングされる仕組み

1. 自国SIMは音声とSMS用に有効のまま。
2. トルコeSIMがモバイルデータを担当。
3. Wi-Fi Callingが通話とSMSをデータ接続越しにルーティング。
4. 自国のネットワークにいるかのように、自宅へ発信し、銀行のSMSを受け取り、電話に応答できる。

### Wi-Fi Callingの要件

- 自国キャリアがWi-Fi Callingに対応している
- スマホがWi-Fi Callingに対応している
- 設定でWi-Fi Callingが有効になっている
- キャリアがトルコでのWi-Fi Callingを許可している

### 衛星SOS：良いバックアップだが、計画ではない

iPhone 14以降は、衛星経由の緊急SOS（Emergency SOS via satellite）に対応しています。トルコには衛星パートナーのカバレッジがない可能性があります。主要な安全手段としては頼らないでください。

これらの設定すべてにまたがる注意点が1つあります。テザリングはスマホ本体と同じデータ上限から消費されます。データ越しの通話品質には、目立つ速度よりもレイテンシが重要です。そしてカバレッジマップの主張は、VoIPのみの通話に旅を託す前に、自分の具体的な海岸線について確認が必要です。

## まとめ：番号とデータの設定

ここまで、IMSIとMSISDN、本物の番号付き現地キャリアプラン、仮想番号、Wi-Fi Callingを見てきました。傾向は、本物のトルコの番号とは現地キャリアプランのことであって、トラベルeSIMではないということです。次に、デュアルSIMによるSMSと2FAの回避策、そしてホットスポットポリシーを扱います。

## SMSと2FAのデュアルSIM回避策

データ専用のトルコeSIMにはMSISDNがなく、SMSを受け取れません。解決策はシンプルです。音声とSMS用に自国SIMを有効のまま保ち、トルコeSIMをモバイルデータに設定し、モバイルデータ切り替えを無効にします。

### トルコeSIMでのデュアルSIM SMS配信の仕組み

自国SIMとトルコeSIMの両方がインストールされていると、スマホは2つのアクティブ回線をサポートします。SMSは、宛先番号に紐づく回線へ配信されます。

**推奨設定：**

- 自国SIM：音声とSMS
- トルコeSIM：モバイルデータ
- 「モバイルデータ切り替えを許可」を無効化

### eSIMがSMSでできないこと

## FAQ：トルコeSIMの番号、通話、SMS、ホットスポット

### eSIMでトルコの電話番号は取得できますか？

はい。ただし、Turkcell、Vodafone Turkey、Türk Telekomの現地トルコキャリアeSIMを通じてのみです。購入にはパスポートでの対面登録が必要です。トラベルeSIMはデータ専用です。

### トルコeSIMはSMSに対応していますか？

いいえ。データ専用のトラベルeSIMはSMSの送受信ができません。SMS認証コードや銀行アラート用に、自国SIMを有効のまま保ちましょう。

### トルコeSIMで通話はできますか？

はい。データ接続越しに、WhatsApp、Telegram、Skype、FaceTimeなどのVoIPアプリを使います。ネイティブの携帯通話には、電話番号付きの現地トルコSIMが必要です。

### トルコeSIMはWhatsAppで使えますか？

はい。WhatsAppはトルコeSIMのデータ接続で機能します。音声・ビデオ通話、メッセージ送信、メディア共有が可能です。

### トルコeSIMは2FAに使えますか？

あなたのトルコeSIMはSMSを受け取れませんが、自国SIMは受け取れます。音声とSMS用に自国SIMを有効のまま保ち、トルコeSIMをモバイルデータに設定しましょう。

### トルコeSIMはホットスポットに対応していますか？

ほとんどの固定データプランはホットスポットを許可します。一部の無制限プランはテザリングを制限または上限設定します。購入前にプラン詳細を確認してください。

### トルコeSIMでWi-Fi Callingは機能しますか？

自国キャリアがWi-Fi Callingに対応し、トルコでの利用を許していれば、機能します。スマホは通話とSMSをトルコeSIMのデータ接続越しにルーティングします。出発前に自国キャリアへ確認してください。iPhoneの設定手順は[AppleのWi-Fi Callingサポート文書](https://support.apple.com/en-us/HT203032)をご覧ください。

### トルコでの家族に最適なホットスポットプランは？

ホットスポット無制限で20 GB以上のプランを探しましょう。SailyとRoamiはホットスポット無制限です。Holaflyは1 GB/日で上限があります。

### トルコで2FAを受け取るための最適な設定は？

物理スロットの自国SIMを音声とSMS用に有効のまま保ち、トルコeSIMをモバイルデータ回線に設定し、「モバイルデータ切り替えを許可」を無効にします。

### トルコeSIMでホットスポットを使いながらSMSも受け取れますか？

はい。音声とSMS用に自国SIMを有効のまま保ちます。トルコeSIMがデータとホットスポットを担当し、SMSは自国の番号に届きます。

- トラベルeSIMが与えるのはデータであって、トルコの番号ではない — 番号が必要なら現地SIMが正解。
- 通話はデータ越しのVoIPで、2FAは自国SIMを有効のまま保つ。
- 現地番号が必要なら、Turkcell、Vodafone、Türk Telekomの現地キャリアプランを買う。
- ホットスポットポリシーを確認する。一部の無制限プランはテザリングを制限するからだ。
