## 簡単な回答：あなたのスマートフォンはeSIMをサポートしていますか？

**最速の確認方法：** ダイヤラーを開き、`*#06#`と入力して、**EID**（32桁のコード）を探します。

- **EIDがある** → スマートフォンにeSIMハードウェアがあります。
- **IMEIのみでEIDがない** → スマートフォンはeSIMをサポートしていません。

**設定での確認：**
- **iPhone：** 設定 → 一般 → 情報 → 「利用可能なSIM」または「キャリアロック」を探す。
- **Samsung：** 設定 → 接続 → SIMマネージャー → 「eSIMを追加」を探す。
- **Google Pixel：** 設定 → ネットワークとインターネット → SIM → 「代わりにSIMをダウンロードしますか？」を探す。

**2018〜2020年以降のほとんどのスマートフォンはeSIMをサポートしています**が、重要な地域別およびキャリア別の例外があります。このガイドでは40以上のデバイス、地域別バージョンの落とし穴、カナダのキャリアロック解除、スマートフォンがeSIMをサポートしていない場合の対処法を扱います。

## カナダeSIM EID確認を30秒で

eSIMを購入する前に、スマートフォンにeSIMハードウェアがあることを確認してください。最速の方法はiPhoneとAndroidの両方で機能します。

### `*#06#`をダイヤルしてEIDを確認

1. **ダイヤラー**を開きます。
2. **`*#06#`**と入力します。
3. **EID**（eSIM識別子）、32桁のコードを探します。

**EIDが表示される場合：** スマートフォンにeSIMハードウェアがあります。  
**IMEIのみが表示される場合：** スマートフォンはeSIMをサポートしていません。

**表示される内容：** iPhoneでは、EIDはIMEIの下に表示されます。Samsungでは、「EID」または「eSIM ID」として表示されることがあります。IMEI番号が2つだけ（IMEI1とIMEI2）表示される場合、スマートフォンにeSIMハードウェアはありません。

### スマートフォンブランド別のeSIM設定確認

- **iPhone：** 設定 → 一般 → 情報 → 「利用可能なSIM」または「キャリアロック」を探す。
- **Samsung：** 設定 → 接続 → SIMマネージャー → 「eSIMを追加」を探す。
- **Google Pixel：** 設定 → ネットワークとインターネット → SIM → 「代わりにSIMをダウンロードしますか？」を探す。
- **その他のAndroidブランド：** 設定で「eSIM」を検索します。

オプションが表示される場合、スマートフォンはeSIMをサポートしています。表示されない場合は、以下の表の地域別の注記を確認してください — 一部のモデルにはeSIMハードウェアがありますが、キャリアによって無効化されているか、特定の地域別バージョンでは欠落しています。

### キャリアロックステータスの確認

スマートフォンがeSIMをサポートしていても、キャリアロック解除されている必要があります。

- **iPhone：** 設定 → 一般 → 情報 → **キャリアロック**が「SIM制限なし」と表示されるはずです。
- **Android：** 設定 → 電話について → ステータス → ネットワーク/SIMステータスを確認します。

カナダでは、CRTCはBell、Rogers、Telus、Freedom Mobileにデバイスの無料ロック解除を義務付けています。[CRTCワイヤレスコード](https://crtc.gc.ca/eng/phone/mobile/codes.htm)をご覧ください。

**重要：** 中国本土と香港で販売されているiPhoneはeSIMをサポートしていませんが、そこの例外は2つだけです — **iPhone 17e（モデルA3635）** と **iPhone Air（モデルA3518）**。その他の中国本土のiPhoneモデルはすべて使用できません。

## カナダでeSIM互換性が重要な理由

### eSIMはソフトウェアではなくハードウェア

eSIMには、スマートフォンに組み込まれた**eUICCチップ**（組み込み型Universal Integrated Circuit Card）が必要です。このチップは物理SIMスロットとは別です。[GSMA](https://www.gsma.com/esim/)はデバイスとキャリア間の相互運用性を確保するためにグローバルeSIM仕様を開発しています。

これはつまり：
- ハードウェアが欠落している場合、ソフトウェア更新でeSIMを追加することはできません。
- 同じスマートフォンモデルでも、地域によってeSIMサポートが異なる場合があります。
- キャリアはハードウェアが存在しても、ソフトウェアロックでeSIMを無効化できます。

### 知っておくべき2026年のeSIM変更点

**eSIM専用スマートフォンが主流になりました。**
- **iPhone 17 Air：** 世界全体でeSIM専用。
- **iPhone 17 / 17 Pro / 17 Pro Max / 17e：** 米国、カナダ、日本、メキシコ、サウジアラビア、UAE、バーレーン、クウェート、オマーン、カタール、グアム、米領バージン諸島を含む12か国でeSIM専用。
- **iPhone 14〜16（米国版）：** eSIM専用。カナダ版のiPhone 14、15、16は物理SIMトレイを保持しています。
- **Google Pixel 10（米国版）：** eSIM専用。
- **Samsung Galaxy S26（一部市場）：** eSIM専用へ移行中。

**重要な訂正：** カナダ版のiPhone 14、iPhone 15、iPhone 16には物理SIMカードトレイがあります。カナダ版iPhone 17シリーズのみがeSIM専用です。これは多くのオンラインガイドでよくある混乱の原因です。

**ミッドレンジスマートフォンがeSIMをサポートするようになりました。**
Samsung Aシリーズ（A54、A55、A56、A57）とGoogle Pixel aシリーズ（8a、9a、10a）がeSIMをサポートするようになりました。

**地域別の違いは依然として大きい。**
同じスマートフォンでも、カナダではeSIMをサポートしていても、中国本土、台湾、韓国ではサポートしていない場合があります。常に正確な地域別バージョンを確認してください。

**情報源に関する注記：** 以下のデバイス互換性情報は、公開されているメーカーのドキュメント、GSMA仕様、Redditなどのコミュニティからのユーザー報告に基づいています。当社独自のテスト主張は提示しません。

### eSIM vs 物理SIM：用語の意味

購入前に、スマートフォンに表示される識別子を知っておくと役立ちます：

- **IMEI（International Mobile Equipment Identity）：** 物理デバイスを識別する15桁の番号。スマートフォンはSIMスロットごとに1つのIMEIを持ちます。
- **EID（eSIM識別子）：** 組み込みeUICCチップを識別する32桁の番号。スマートフォンにEIDがあれば、必要なハードウェアを持っています。
- **ICCID（Integrated Circuit Card Identifier）：** 特定のSIMプロファイルのシリアル番号 — 物理または組み込み。
- **キャリアロック：** ロック解除されるまでスマートフォンを1つのネットワークに結びつけるソフトウェア制限。
- **デュアルSIM：** 2つの回線を同時に実行すること。通常は1つの物理nano-SIM＋1つの組み込みプロファイル、または2つの組み込みプロファイル。

これらの用語を知っていると、以下の互換性チェックがより早く理解でき、地域別バージョンの注記を混乱なく読むことができます。

### カナダでのSamsung eSIMキャリアロック解除

カナダのキャリアが販売するSamsungデバイスは、しばしばeSIMが無効化されています。修正方法は以下の通りです：

1. **キャリアに電話：** Bell、Rogers、Telus、またはFreedom Mobile。
2. **eSIMの有効化とネットワークロック解除を依頼。** CRTCは無料ロック解除を義務付けています。
3. **IMEIを提供：** `*#06#`をダイヤルして取得します。
4. **確認を待つ：** 通常1〜2営業日。
5. **スマートフォンを再起動してSIMマネージャーを確認：** 「eSIMを追加」が表示されるはずです。

**キャリアが拒否した場合：** CCTS（電気通信・テレビジョンサービス苦情委員会）に苦情を申し立ててください。

## カナダのキャリアロックとeSIMロック解除手順

スマートフォンがeSIMをサポートしていても、サードパーティのeSIMを使用するにはキャリアロック解除されている必要があります。

カナダでは、CRTCはBell、Rogers、Telus、Freedom Mobileにデバイスの無料ロック解除を義務付けています。[CRTCワイヤレスコード](https://crtc.gc.ca/eng/phone/mobile/codes.htm)をご覧ください。

### スマートフォンがロックされているか確認する方法

- **iPhone：** 設定 → 一般 → 情報 → **キャリアロック**。「SIM制限なし」と表示されるはずです。
- **Android：** 設定 → 電話について → ステータス → ネットワーク/SIMステータスを確認します。

### カナダのキャリアロックを解除する方法

1. **ロックステータスを確認**（上記参照）。
2. **キャリアに連絡：** Bell、Rogers、Telus、またはFreedom Mobile。
3. **無料ロック解除を依頼。** CRTCが義務付けています。
4. **IMEIを提供：** `*#06#`をダイヤルして取得します。
5. **確認を待つ：** 通常1〜2営業日。
6. **非キャリアSIMを挿入**するか、サードパーティのeSIMをインストールしてみてください。動作すれば、スマートフォンはロック解除されています。
7. **eSIMが無効のままの場合（Samsung）：** キャリアにeSIMを特別に有効化するよう依頼してください。一部のキャリアはデフォルトで無効化しています。

**プロのヒント：** カナダのキャリアから中古のSamsungを購入した場合、eSIMが永久に無効化されている可能性があります。購入前にキャリアに確認してください。
