## トルコeSIMの3つの互換性チェックとは？

トルコeSIMのインストールには、3つのチェックすべての合格が必要です。1つでもスキップすると、インストールは失敗します。EIDチェックはハードウェアを確認します。SIMロックチェックは許可を確認します。地域版チェックは、特定市場向けにハードウェアが物理的に取り除かれていないことを確認します。

### トルコeSIMインストールのためのEID確認

EIDは、eUICCチップに焼き込まれた32桁の番号です。設定にEIDが表示されるなら、スマホはeSIMに必要なハードウェアを持っています。EID欄がなければ、スマホにはeUICCハードウェアが一切ありません。ソフトウェアの更新で追加はできません。

**iPhone：** 設定 → 一般 → 情報 → 「EID」までスクロール

**Android：** 設定 → 端末情報 → 状態情報 → 「EID」。メーカーによっては設定 → ネットワークとインターネット → SIM にある場合もあります。

EIDチェックは60秒以内で済み、最も信頼できる互換性テストです。

### トルコeSIMインストールのためのSIMフリー確認

SIMロックされたスマホは、販売したキャリアのSIMプロファイルに制限されます。サードパーティのeSIMプロファイルはインストールできません。

**iPhone：** 設定 → 一般 → 情報 → 「SIMロック」。「SIM制限なし」と表示されるはずです。キャリア名が表示されるなら、ロックされています。

**Android：** 設定 → 端末情報 → SIMロック、またはキャリア以外のSIMを挿入して受け付けられるか確認します。

ロックされたスマホは、インストール中にトルコeSIMプロファイルを拒否します。ロック解除にはキャリアへの連絡と、契約の完済またはロック解除料金の支払いが必要です。これはトルコ国内からはできません。

### トルコeSIMに対応した地域版モデル

人気スマホの一部の地域版モデルには、グローバルモデルに含まれるはずのeUICCハードウェアが一切ありません。最も重要な例外はAppleです。中国本土、香港、マカオで販売されたiPhoneには、eSIMの代わりに物理デュアルSIMトレイがあります。eUICCチップは物理的に存在しません。

中国本土で販売されたSamsungとGoogleの端末も、現地規制によりeSIM対応を欠くことがあります。グローバル版は一般にeSIMに対応しています。

| チェック | 確認できること | 確認方法 |
|---|---|---|
| EID | eUICCハードウェアの存在 | 設定 → 情報 → EID |
| SIMロック | サードパーティeSIMの許可 | 設定 → 情報 → SIMロック |
| 地域版 | eUICCチップが取り除かれていない | メーカーの地域別仕様書を確認 |

## トルコeSIMの5分の購入前ワークフロー

トルコeSIMを買う前に、このワークフローを実行しましょう。最もよくある失敗パターン — EIDなし、SIMロック、eUICCのない地域版、満杯のeSIMスロット、キャリアのソフトウェアブロック — を防げます。

### まずEIDを確認

設定を開き、「EID」を検索します。欄が存在し32桁の数字が表示されれば、ハードウェアがあります。なければ、そこで終了です。あなたの端末はeSIMを使えません。

### 次にSIMロックを確認

iPhoneなら、設定 → 一般 → 情報 → SIMロックへ。「SIM制限なし」と表示される必要があります。Androidなら、設定 → 端末情報 → SIMロック、またはキャリア以外のSIMを挿入します。スマホがSIMを拒否するなら、ロックされています。

### 地域版を確認

自分の正確なモデル番号をオンラインで検索し、eSIM対応を確認しましょう。モデル番号は、iPhoneなら設定 → 一般 → 情報、Androidなら設定 → 端末情報にあります。マーケティング名だけで判断しないでください。香港で買ったiPhone 15は、英国で買ったiPhone 15と同じではありません。これが重要である規制的な背景の全体は、[ブロックルール](/blog/turkey-esim-ban-availability-rules/)をお読みください。

### 空きeSIMスロットを数える

eSIM対応のスマホでも、すでに2つのアクティブ回線を持つことがあります。iPhone 13以降は2つのアクティブeSIMに対応しています。ほとんどのAndroidはeSIM1つ＋物理SIM1枚です。すでにデュアルSIMを使っている場合、トルコeSIMの追加には1つの回線の無効化が必要になることがあります。

### キャリアのソフトウェアブロックに注意

米国キャリア版は、ハードウェアが対応していても、ソフトウェアでeSIMが無効化されていることがあります。Verizon、AT&T、T-Mobile経由で販売されたSamsung端末でよく見られます。スマホが米国キャリア製でまだロックされているなら、解除するまでeSIMはブロックされていると想定してください。

### トルコeSIMチェックに不合格だったら

| 不合格チェック | 意味 | やること |
|---|---|---|
| EIDなし | eUICCハードウェアなし | 物理SIM、ポケットWi-Fi、セカンダリ端末を使う |
| SIMロック | サードパーティeSIMがブロック | 購入前にキャリアにロック解除を依頼 |
| 地域版 | eUICCが取り除かれている | 別の端末か物理SIMを使う |
| eSIMスロット満杯 | 空きプロファイルスロットなし | 回線を無効化するかセカンダリ端末を使う |
| キャリアのソフトウェアブロック | キャリア版ビルドでeSIMが無効 | ロック解除するか別の端末を使う |

iPadのトルコeSIMはデータ専用です。ブラウジング、マップ、動画ストリーミング、メッセージアプリは使えます。ネイティブの携帯通話やSMSはできません。iPadには音声電話のスタックがないからです。

iPadをセカンダリ端末として持ち歩く旅行者にとっては、通常は問題ありません。iPadは同じトルコeSIMデータプランに接続し、通話はVoIPアプリが処理します。SMS認証のためにトルコの電話番号が必要な場合、iPadはそれを提供できません。回避策の全体は[ホットスポットガイド](/blog/turkey-esim-number-calls-sms-hotspot/)をお読みください。

iPadにトルコeSIMがあり、スマホにはない場合、iPadをホットスポットとして使えます。Wi-FiのみのスマホやeSIM非対応のスマホを持つ旅行者に有用です。iPadがWi-Fi経由でデータ接続を共有し、スマホがそこへ接続します。

**向いている人：** 2週間以上の滞在で、トルコの電話番号が必要な旅行者。

### トルコeSIMの代替としてのポケットWi-Fi

ポケットWi-Fi端末は、複数端末で共有できる現地Wi-Fiホットスポットを作ります。イスタンブール空港でレンタルするか、ホテルへの配送を手配できます。端末は現地トルコSIMを使うため、eSIM互換性の問題を丸ごと回避できます。

**向いている人：** 複数端末のある家族やグループ。

### トルコeSIMの代替としてのセカンダリeSIMスマホ

引き出しに眠っている古いeSIM対応スマホ（iPhone XSやPixel 3など）があれば、トルコ旅行専用のホットスポット端末として使えます。セカンダリスマホにトルコeSIMをインストールし、ホットスポットを有効にし、メインのスマホをWi-Fiで接続します。

**向いている人：** すでにスペアのeSIM対応端末を持っている旅行者。

### トルコeSIMの代替としてのWi-FiとVoIP

ホテル、Airbnb、訪れる場所に信頼できるWi-Fiがあれば、それに頼り、通話はVoIPアプリで行えます。限界は、Wi-Fiがどこでもあるわけではないことです。特にナビゲーション中、タクシーを呼ぶとき、探索中には不便です。

**向いている人：** 常時接続を必要としないライトユーザー。

## 中古端末と法人端末のeSIM

中古スマホと法人管理端末には、標準のチェックリストが見落とす追加の互換性リスクがあります。EIDチェックだけが、 refurb や地域ミックスの端末でeSIM対応を確認する信頼できる方法です。

### トルコeSIMの中古iPhoneのリスク

中古iPhoneは、売り手がロック解除済みと言っても、まだSIMロックされていることがあります。ロックはIMEIに紐づき、元の所有者が契約を延滞すると再適用されることがあります。トルコ旅行用に中古iPhoneを買う前に、設定 → 一般 → 情報 → SIMロックを確認してください。「SIM制限なし」と表示される必要があります。

### トルコeSIMの法人MDM制限

雇用主がモバイル端末管理（MDM）で管理するスマホは、会社のポリシーによりeSIMインストールがブロックされていることがあります。MDMプロファイルは、ハードウェアが対応していても、新しいeSIMプロファイルの追加を妨げられます。スマホが雇用主に管理されている場合、トルコeSIMを買う前にIT部門へ確認してください。

### トルコeSIMのrefurbと地域版のリスク

refurb（再生端末）は、地域をまたぐパーツから組み立てられることがあります。refurbのiPhoneには、中国市場のロジックボードと米国市場の画面が入っていることもあります。EIDチェックだけが、eSIM対応を確認する信頼できる方法です。

### 中古端末のトルコeSIM向けチェック方法

1. 設定でEIDを確認する。
2. 設定でSIMロックを確認する。
3. モデル番号をメーカーの地域別仕様書と照合する。
4. 売り手に最初の購入レシートを求める。
5. 購入前にキャリア以外のSIMでテストする。

## eSIM移行と端末の買い替え

eSIMプロファイルは単一のEIDに紐づきます。スマホを買い替えるとき、プロファイルを新しい端末にそのまま移すことはできません。新しいQRコードか、プロバイダーの移行手続きが必要です。元のQRコードは使い切りです。

### なぜトルコeSIMのQRコードは使い切りなのか

QRコードは1回限りの認証情報です。プロファイルがある端末のEIDにダウンロードされると、同じQRコードで別の端末にプロファイルをインストールすることはできません。古いスマホからプロファイルを削除しても、QRコードは消費済みのままです。プロバイダーに新しいQRコードを依頼する必要があります。この挙動は[GSMA SGP.22 eSIM仕様](https://www.gsma.com/esim/)で定義されています。

### トルコeSIMを移行する方法

1. 古いプロファイルを削除する前に、プロバイダーの移行ポリシーを確認する。
2. アプリやウェブサイトでeSIM移行を許すプロバイダーもある。
3. 新しいQRコードの発行を求められるプロバイダーもある。
4. プロバイダーがBTKにブロックされている場合、トルコ国内から移行手続きにはアクセスできない。
5. 移行は出発前か、トルコ出国後に行う。

### トルコeSIMの端末買い替えチェックリスト

- [ ] 新しい端末にEIDがあることを確認する
- [ ] 新しい端末がSIMフリーであることを確認する
- [ ] 新しい端末が同じeSIM規格に対応していることを確認する
- [ ] 必要ならプロバイダーに新しいQRコードを依頼する
- [ ] 出発前にWi-Fiで新しいプロファイルをインストールする
- [ ] 古いプロファイルは、新しい方が動いてから削除する
